# Scratch V5 测试诊断与优化方向

## 独立测试结论

- 固定阈值 0.300274：Recall 0.806、Precision 0.556、F1 0.658、正常误报率 0.168。
- 混淆矩阵：TP 25、FP 20、TN 99、FN 6；未达到 Recall >= 0.95 的目标。
- 31 张划痕样本较少，Recall 的 Wilson 95% 区间约为 0.637–0.908；需要更多独立正样本确认稳定性。
- 验证集预先保存的激进阈值 0.203814 在测试集上 Recall 0.935，但正常误报率升至 0.588，不适合作为默认生产阈值。

## 错误模式

- 6 张漏检以正视/斜视为主，划痕区域较小、低对比，整图缩放后容易被正常齿轮纹理淹没。
- 漏检样本分类器均值为 0.455、检测器均值为 0.144，两条分支同时偏低，单纯修改融合权重无法根治。
- 20 张误报中包含大量侧视齿面高光和正面正常加工纹；误报分类器均值高达 0.814，说明分类器学到了反光/纹理捷径。
- 测试集与 train/val 没有 SHA256 完全重复。简单 dHash 出现大量相似对，但该场景背景和轮廓高度一致，dHash 只能作为复核提示，不能据此认定泄漏。

## V6 优先实验

1. 保持 `test_scratch` 锁定，不把这 150 张图加入训练或阈值搜索；另采同分布训练数据和第二套未来盲测集。
2. 使用第一阶段齿轮模型裁出并归一化齿轮 ROI，训练“整齿轮 + 2x2/3x3 重叠局部块”的多实例分类器，以 top-k/max 池化汇总局部划痕概率。
3. 局部分支输入 RGB、CLAHE 和高通/梯度表示；整图分支保留 EfficientNet-B0，并比较 ConvNeXt-Tiny、EfficientNetV2-S。
4. 增加视角路由：正视/斜视使用局部纹理分支，侧视增加独立分类头或阈值；重点补充无划痕侧齿高光、圆周加工纹等困难负样本。
5. 训练时按 `scratch/normal × face/oblique/side × 拍摄批次` 均衡采样，正样本局部块使用 XML 引导，但最终仍输出图像级 PASS/REJECT。
6. 损失函数比较 focal loss、asymmetric focal loss 和 Recall 约束下的 class weight；困难样本最多重采样 3 倍，禁止使用测试误判直接训练。
7. 在验证集重新搜索全局/局部/检测器融合和阈值；先满足 FPR <= 0.20，再最大化 Recall。候选锁定后才能再次运行新的独立测试集。

## 建议验收

- 验证集和新盲测集均达到 Recall >= 0.95、正常误报率 <= 0.20。
- 每个视角至少 30 张独立划痕图；分别报告正视、斜视、侧视 Recall。
- 额外报告低对比划痕 Recall、侧齿高光误报率，并保存全部 FN/FP 联系图。
