# GearPro技术报告术语对照表

本表用于正文、表格和图内文字的一致性检查。名称依据实际方法、相关论文常用表述及项目负责人对缺陷含义的确认确定；中文译名不声称是唯一强制标准。原始代码、模型版本、JSON字段与文件路径保留原名。

## 1　任务、模型与缺陷名称

| 原表述 | 统一用语 | 英文或历史代码 | 使用说明 |
|---|---|---|---|
| 专项、专项化 | 按缺陷类别分别建模 | defect-specific modeling | 描述划痕与齿部缺损分别建立模型的安排 |
| 划痕专项 | 划痕检测子系统 | Scratch V5 | 包含两个图像分类模型与一个目标检测模型 |
| 缺口专项、缺孔 | 齿部缺损检测子系统 | Missing Hole V1；missing_hole | 缺陷以齿侧、齿角的局部缺损为主，不译为孔洞缺失 |
| 缺齿缺口、结构缺口 | 齿部缺损 | partial tooth damage | 总称；明确完整齿缺失时才单独称缺齿 |
| 双专项 | 两类缺陷检测子系统 | two defect-detection subsystems | 不是两个单一神经网络，也不是共享主干的多任务网络 |
| 分支 | 成员模型 | member model | 指独立训练的网络；真实网络内部的branch按结构另行说明 |
| 标准头 | 原始YOLO26n检测模型 | original YOLO26n detector | 标明对照模型，避免“标准”的范围不明 |
| P2检测头 | 包含P2检测层的YOLO模型 | YOLO detector with a P2 detection layer | 描述检测尺度配置，避免误解成项目新提出的头 |
| 统一模型 | 统一缺陷分类模型 | unified defect classifier | 图像包含任一类缺陷即为正样本 |
| 局部响应 | 预测框置信度或局部特征 | detection confidence / local features | 讨论输出时写置信度，讨论中间表征时才写特征 |
| 最高框分数 | 预测框的最大置信度 | maximum detection confidence | 当前目标检测模型的图像级原始分数 |

## 2　融合与分数处理

| 原表述 | 统一用语 | 英文 | 使用说明 |
|---|---|---|---|
| 校准融合 | 温度缩放与分数融合 | temperature scaling and score fusion | 是先后两项操作，不合并成新方法名 |
| 分类均值 | 分类模型分数的平均值 | average classifier score | 先对两个分类成员的分数取算术平均 |
| 加权组合 | 分数级加权融合 | score-level weighted fusion | 本文具体使用加权平均，保留公式及系数来源 |
| 双专项OR、逻辑OR | 基于或规则的决策级融合 | decision-level fusion using the OR rule | 两个子系统分别阈值判定后合并二值结果 |
| soft-OR（代码名） | 最大值融合规则 | maximum rule | 连续分数取max，与二值或规则分别解释 |
| 温度权重 | 温度参数 | temperature parameter | 温度用于分数缩放，不是投票或融合权重 |
| 概率、综合概率 | 模型输出分数、融合分数 | model score / fused score | 保留概率校准方法名，不宣称融合值已等于真实发生概率 |
| 独立阈值后OR | 分别进行阈值判定，再按或规则合并 | thresholding followed by OR fusion | 任一子系统判为有缺陷，最终即判为有缺陷 |

同类缺陷的加权融合操作明确为分数级融合；最终跨缺陷类别的二值判定合并明确为决策级融合。部分文献也将连续输出组合归入广义决策融合，因此报告优先写出计算公式，避免仅靠分类名称推断实现。

## 3　实验、数据与评价

| 原表述 | 统一用语 | 英文或定义 | 使用说明 |
|---|---|---|---|
| 先导 | 初步实验 | pilot experiment | 用较低训练轮数上限比较候选配置 |
| 长训、完整复训 | 增加训练轮数上限的重新训练 | retraining with a larger epoch limit | 已核对训练代码：从预训练初始化重新训练，不写成接续训练 |
| 难例精炼 | 困难样本重采样与CLAHE增强实验 | hard-example resampling and CLAHE augmentation | 写出实际操作，不用抽象修饰替代方法 |
| 排行榜 | 候选模型评价表 | candidate-model evaluation table | 表示归档验证结果；JSON名leaderboard不改 |
| 胜出 | 按既定验证规则选用 | validation-based model selection | 不是统计显著性或全局最优结论 |
| 命中 | 判为有缺陷，或正确检出 | positive prediction / true positive | 前者只描述预测；后者还需与参考标注一致 |
| 筛出可靠性 | 精确率 | precision=TP/(TP+FP) | 不与准确率accuracy混用 |
| 缺陷检出率 | 召回率 | recall=TP/(TP+FN) | 可在解释中注明等价关系 |
| 正常件误筛 | 正常样本误报 | false positive | 需说明负样本是无划痕、无齿部缺损还是无两类缺陷 |
| 误报率 | 误报率（FPR） | FP/(FP+TN) | 与FP/(TP+FP)不同 |
| 筛出比例 | 预测为缺陷的样本比例 | (TP+FP)/N | 仅当全部疑似件送复核时等于送复核比例 |
| 真值、真值框 | 参考标注、标注框 | ground truth annotations / boxes | 指人工标注参考，不意味机械性能已独立测定 |
| difficult | 困难目标 | difficult=1 | 确定有缺陷，但小、低对比或遮挡导致难辨认 |
| 困难样本 | 含困难目标的图像 | image containing difficult objects | 区分含部分困难目标与仅含困难目标 |
| 实体、实体级隔离 | 齿轮工件、按工件分组划分数据 | grouping by physical gear | 与图片顺序编号及近重复图像组不同 |
| 口径 | 具体评价条件 | evaluation conditions | 写出任务标签、分母、测试集及困难目标处理方式 |
| 框级评价 | 目标级定位评价 | object-level localization evaluation | 根据预测框与标注框的匹配计算指标 |
| 工作点、运行点 | 阈值及其对应的评价结果 | operating point | 并非错误术语；正文尽量直接说明阈值、Recall与FPR |
| 工程先验 | 预先固定的参数、经验设定 | fixed parameters / empirical settings | 不与概率分布的统计先验混用 |
| 配置冻结 | 固定模型及判定参数 | fixing models and decision parameters | 明确包括温度、融合权重与阈值 |
| 历史留出 | 曾用于指导后续实验的留出测试集 | previously inspected holdout test set | 直接交代其使用历史 |
| 计数冷却 | 重复计数抑制间隔 | duplicate-count suppression interval | 此名称只解释软件行为，不构成工件追踪功能 |

“温度缩放、正负样本、消融实验、全因子试验设计、感兴趣区域、非极大值抑制”等已有术语保留并按实际方法定义。三个因素的12种组合属于全组合比较，结构和batch同时变化的结果不解释为严格单因素消融。
