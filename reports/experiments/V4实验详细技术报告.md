## 1 结论与适用范围

V4 将 scratch 与 missing_tooth 合并为一个 `defect` 正类，只判断整张齿轮图像应当通过还是剔除，不输出缺陷类型和位置。正式流程完成了 18 个候选训练和 2 个 120 epoch 上限的完整复训，共 20 个进入单模型排行榜的实验；之后从 8 个强且架构多样的候选中穷举 470 种成员与融合方式组合，并仅用验证集选择最终三模型最大概率融合。

最终成员是 `xfull_resnet18_384_w1_s73_r1`、`x_yolo_384_w1_s17` 和 `p_resnet18_512_w4`。三个模型分别执行四路 TTA 和温度缩放，融合分数取三者缺陷概率最大值。验证集选择默认阈值 0.702842226；验证结果为 Recall 0.933、Precision 0.848、FPR 0.250。50 张历史留出集上的最终结果为 Recall 0.633、Precision 0.731、F1 0.679、FPR 0.350、AUROC 0.707、AUPRC 0.814，混淆矩阵 TP/FP/TN/FN=19/7/13/11。

预设目标是 Recall ≥0.95 且 FPR ≤0.30。最终版本两项均未同时达到：测试 Recall 低 0.317，FPR 高 0.050。scratch Recall 只有 0.364，是主要瓶颈；missing_tooth Recall 为 0.789。该模型适合辅助筛选、人工复核和难例收集，现有证据不足以支持无人值守自动剔除。

## 2 任务定义与评估目标

图像标签定义为 `y=1` 当原始类别是 scratch 或 missing_tooth，`y=0` 当类别是 normal。推理输出校准后的 `defect_probability`。当融合概率 `p_fused ≥ threshold` 时输出 `REJECT`，否则输出 `PASS`。

主要选择约束为验证集 normal FPR 不高于 0.30，并在约束内优先最大化 Recall。报告同时保留 FPR 上限 0.10、0.20、0.30、0.50 的单模型运行点；最终融合另外计算无 FPR 限制的 1.0 档，用于高敏感阈值。FPR 0.30 档是默认生产候选，1.0 档仅是高敏感辅助模式，不能解释为质量目标已经放宽后仍然合格。

| 符号或指标 | 定义 |
| --- | --- |
| TP | 缺陷图被判为 REJECT |
| FN | 缺陷图被判为 PASS |
| FP | normal 图被判为 REJECT |
| TN | normal 图被判为 PASS |
| Recall | TP / (TP + FN) |
| Precision | TP / (TP + FP) |
| FPR | FP / (FP + TN) |
| Specificity | TN / (TN + FP) = 1 − FPR |
| F1 | 2 × Precision × Recall / (Precision + Recall) |
| NPV | TN / (TN + FN) |

## 3 数据来源 拆分与防泄漏

V4 复用 V3 的样本加载与近重复分组函数。程序按 `train_001` 至 `train_343` 逐张读取图片；XML 中必须只包含一种缺陷类，框坐标必须落在图像边界内。原始分布为 scratch 79、missing_tooth 132、normal 132；合并后二分类分布为 defect 211、normal 132。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 56 | 95 | 151 | 92 | 243 | 90 | 95 | 58 |
| val | 12 | 18 | 30 | 20 | 50 | 22 | 19 | 9 |
| test | 11 | 19 | 30 | 20 | 50 | 20 | 18 | 12 |

### 3.1 视角推断

设图像长短边比 `r=max(width/height, height/width)`。当 r≥1.8 时标为 side；1.25≤r<1.8 时标为 oblique；否则标为 face。视角只用于拆分平衡、采样平衡和分组评估，不作为模型输入标签。

### 3.2 近重复分组

每张图先缩放为 9×8 灰度图，比较相邻列像素得到 64 位 dHash。两图 dHash 汉明距离不超过 2 时无条件并组。对于编号相距不超过 3 的图片，如果 dHash 距离为 3 至 8、宽高比相对差不超过 0.15、64×64 去均值归一化灰度向量的点积不低于 0.92，也会并组，但这一规则将连通分量大小限制为不超过 12。

最终得到 159 个组，最大组 41 张。V4 以 70%/15%/15% 为目标，在类别×视角九个分层上搜索 300 次分组方案，随机种子为 20260911。候选 val/test 只从组大小不超过 20 的组中选择，因此超大组留在 train。拆分后穷举跨集合图像对，dHash 距离不超过 2 的泄漏对为 0。

### 3.3 拆分代价函数

对 val 和 test 逐组贪心选择。候选组的代价由三部分构成：总样本数偏差、九个类别×视角分层偏差、超过目标样本数 3 张后的强惩罚。可写为：

`cost(g)=3×|N_after−N_target|/N_target + Σ_k |n_after,k−t_k|/max(1,t_k) + 10×max(0,N_after−N_target−3) + ε`

其中 ε 是用于打破并列的极小随机数。300 次完整方案再按所有 split 和 strata 的绝对偏差总和选择误差最小者。这个设计降低近重复泄漏，但也使 val/test 更接近“跨拍摄组”泛化测试，因此指标明显低于随机逐图拆分通常得到的结果。

## 4 V4 完整实验流程

1. 加载 343 张图片与 XML，合并为 normal/defect 二分类标签。
2. 建立 159 个近重复组，按类别与视角分层生成固定 train/val/test 清单并执行泄漏检查。
3. 运行 9 个基础候选，对比 YOLO26n-cls、ResNet18、EfficientNet-B0、384/512 输入和 defect 权重 1/2/4。
4. 保存第一次基线测试：ResNet18 512 w4，四路 TTA，温度 2.025，默认阈值 0.640567。
5. 增加 6 个不同随机种子的 RGB 候选和 3 个纹理 ResNet18 候选，扩大架构与随机性覆盖。
6. 从单模型验证结果中选择靠前候选进行 120 epoch 上限完整复训，正式排行榜保留 2 个完整复训结果。
7. 每个单模型分别比较无 TTA 与四路 TTA，随后对概率执行温度缩放，并在不同 FPR 上限下扫描阈值。
8. 从 AUPRC 靠前且每个模型族最多 3 个的规则中选出 8 个组合候选，穷举 1 至 4 个成员及 mean、max、rank_mean 融合，共 470 种配置。
9. 只用验证集按“满足 FPR≤0.30、Recall 最大、FPR 更低、AUPRC 更高、成员更少”的优先级选出最终三模型 max 融合。
10. 固定成员、TTA、温度、融合方式和阈值后，对 50 张历史留出图生成最终逐图结果与混淆矩阵。

## 5 公共训练 推理与选择参数

### 5.1 自定义 ResNet18 与 EfficientNet B0 公共参数

| 参数组 | 完整有效值 |
| --- | --- |
| 初始化 | torchvision ImageNet 默认预训练；ResNet18 `fc` 或 EfficientNet-B0 `classifier[1]` 替换为单输出线性层 |
| 输入整形 | 保持宽高比缩放，使长边等于 imgsz；在 RGB=(238,238,238) 的正方形画布居中填充 |
| 归一化 | mean=(0.485,0.456,0.406)，std=(0.229,0.224,0.225) |
| 优化器 | AdamW；lr=3e−4；weight_decay=5e−4 |
| 学习率 | CosineAnnealingLR；T_max=实验 epoch 上限；eta_min=1e−6 |
| 损失 | BCEWithLogitsLoss；pos_weight 由实验的 defect_weight 给出 |
| batch | imgsz 384 时 24；imgsz 512 时 12 |
| 数据加载 | workers=4；pin_memory=true；persistent_workers=true；WeightedRandomSampler replacement=true |
| 混合精度 | CUDA autocast float16 与 GradScaler |
| 早停 | epoch 上限≤30 时 patience=10；否则 patience=16 |
| 最佳权重规则 | 先最大化验证 Recall，再最小化验证 FPR；每个 epoch 的阈值均在 FPR≤0.30 下扫描 |
| 硬件要求 | CUDA；现有基线报告记录 NVIDIA GeForce RTX 4060 Laptop GPU |

训练增强按代码顺序执行：75% 概率从水平翻转、垂直翻转、旋转 90°、旋转 270°中随机选一种；65% 概率执行 brightness 0.82–1.18 和 contrast 0.80–1.22；25% 概率执行 LAB L 通道 CLAHE，clipLimit=2.0、tileGridSize=8×8；15% 概率 GaussianBlur，半径 0.1–1.0；20% 概率加入标准差 1–5 的高斯噪声；20% 概率执行 gamma 0.82–1.18。验证与测试不做随机增强。

采样权重为 `w_i = 1 / n_(category,view)`。因此 scratch/face、scratch/oblique、scratch/side、missing_tooth 各视角和 normal 各视角在期望抽样频率上被拉平。该采样与 BCE 正类权重是两种不同机制：前者平衡类别×视角出现频率，后者直接放大正类损失梯度。

当前源码没有执行 JPEG 压缩增强。部分历史总结文字提到 JPEG，但训练实现中没有对应编码/解码操作；本报告以可执行源码为准。

### 5.2 纹理 ResNet18 表示

纹理模型先把 RGB 转为灰度 G，再对 G 做 CLAHE 得到 C，并用 3×3 Laplacian 计算边缘绝对值，线性归一化为 E。最终三通道输入是 `[G,C,E]`，之后再执行正方形填充与 ImageNet 数值归一化。其目的不是保留颜色，而是同时提供原始亮度、局部对比度和二阶边缘响应。

### 5.4 TTA 温度缩放与运行点

`none` 只用原图；`tta_mean` 使用原图、水平翻转、垂直翻转和 CLAHE 四个版本，取四次缺陷概率的算术平均。每个实验分别比较两种方式，按 FPR≤0.30、Recall、较低 FPR、AUPRC 的顺序选出更优方式。

温度 T 在 0.35 至 4.00 的 147 个等距点上扫描，步长 0.025。用验证集二元交叉熵 NLL 最小的 T 校准概率。温度达到上界 4.0 表示最佳值落在搜索边界，不能据此断言真实最优温度就是 4.0。

## 6 每次正式实验的完整参数 内容与结果

本章每个实验的“完整参数”由第 5 章模型族公共参数与对应小节的差异参数共同组成。这样既保留全部有效值，又避免在 20 个实验下重复数百行相同字段。结果以进入模型与融合选择的校准后验证指标为主；训练历史中的原始逐 epoch 阈值不等同于温度校准后的最终阈值。

## 9 方法 算法与公式

### 9.1 带正类权重的二元交叉熵

自定义网络输出 logit z，概率 p=σ(z)。单样本损失为：

`L = −[w_pos × y × log(p) + (1−y) × log(1−p)]`

w_pos 分别测试 1、2、4。提高 w_pos 会加大漏检正类的梯度代价，但可能提高 normal 误报；V4 的结果证明收益不是单调的。

### 9.2 余弦退火学习率

自定义网络学习率近似为：

`lr_t = eta_min + 0.5 × (lr_0−eta_min) × [1+cos(πt/T_max)]`

其中 lr_0=3e−4，eta_min=1e−6，T_max 等于实验 epoch 上限。早停可能在完整余弦周期结束前终止训练。

### 9.3 CLAHE 与 Laplacian 纹理通道

CLAHE 在 8×8 网格内限制局部直方图对比度，clipLimit=2.0；Laplacian 使用 3×3 核近似二阶导数，取绝对值并归一化到 0–255。纹理模型的输入是 `[gray, CLAHE(gray), normalize(|Laplacian(CLAHE(gray))|)]`。

### 9.4 TTA 概率平均

四路 TTA 为原图、水平翻转、垂直翻转、CLAHE。单模型原始 TTA 分数：

`p_TTA = (p_original + p_hflip + p_vflip + p_CLAHE) / 4`

它降低某一种视图变换造成的偶然波动，但会让每张图的推理次数增加到 4 次。最终三模型系统共执行 12 次模型前向。

### 9.5 温度缩放

先把概率转为 logit：`l=log[p/(1−p)]`，再计算 `p_T=σ(l/T)`。T 由验证集 NLL 最小化得到：

`NLL(T)=−(1/N)Σ[y_i log p_T,i +(1−y_i)log(1−p_T,i]`

T>1 会压缩过度自信概率，使其更接近 0.5。温度缩放通常不改变单模型样本排序，但会改变固定阈值和不同模型概率融合的数值关系。

### 9.6 阈值扫描与字典序选择

候选阈值集合为 `{0,1} ∪ {所有验证概率}`。对每个阈值计算混淆矩阵。单模型选择键为：

`key = (FPR≤cap, Recall, −FPR, Precision)`

Python 元组按字典序取最大，因此先保证是否满足约束，再最大化 Recall，再降低 FPR，最后提高 Precision。这个规则解释了为什么阈值不一定最大化 F1。

### 9.7 AUROC 与 AUPRC

AUROC 由按概率降序得到的 ROC 折线用梯形法积分；AUPRC 使用 Recall 增量乘以当前 Precision 的阶梯积分。由于 val 只有 30 个正类、20 个负类，Recall 的最小步长约 0.0333，FPR 的最小步长为 0.05，指标呈明显离散台阶。

### 9.8 三种融合

对 M 个模型的校准概率：mean 为 `(1/M)Σp_m`；max 为 `max_m p_m`；rank_mean 先在 50 张验证图内部将每个模型分数映射到 0–1 等距秩，再对各模型秩取平均。max 融合体现“任一模型强烈认为有缺陷就剔除”，符合高召回任务，但也容易增加 FP。

## 10 误差分析 证据边界与限制

### 10.1 主要误差

最终模型漏掉 11/30 个缺陷，其中 7/11 张 scratch 被漏检，scratch Recall 0.364；missing_tooth 漏 4/19，Recall 0.789。按视角，face/oblique/side Recall 分别为 0.556/0.615/0.750。低对比划痕和跨拍摄组外观变化仍是核心问题。

max 融合把基线测试 Recall 从 0.567 提到 0.633，但 FPR 从 0.300 升到 0.350。提升来自多个模型对不同缺陷样本的互补响应，代价是只要任一成员在正常图上产生高分就会触发误报。

### 10.2 测试集性质

第一次基线测试结果已被用于判断扩展方向，随后又在相同 50 张留出图上报告扩展单模型与最终融合。因此最终测试仍是固定留出评估，但不再是完全未查看的一次性盲测。最终成员和阈值的具体计算只使用验证集，这能降低直接测试调参，但无法消除研究方向受早期测试反馈影响的选择偏差。

### 10.3 小样本不确定性

测试只有 30 个缺陷和 20 个正常。多识别一张缺陷，Recall 改变 0.0333；多误报一张 normal，FPR 改变 0.05。最终 FPR 0.35 与目标 0.30 的差距只对应一张 normal，但最终 Recall 与 0.95 的差距对应约 9.5 张缺陷，召回不足不是单个样本波动能解释的。

### 10.4 选择过拟合风险

470 个融合配置都在同一个 50 张验证集上比较，存在多重比较与验证集过拟合风险。脚本用“候选池限 8 个、每族最多 3 个、最多 4 个成员、并列时偏好更少成员”来控制复杂度，但不能完全消除风险。下一轮应使用新拍摄批次作为从未查看的独立测试集。
