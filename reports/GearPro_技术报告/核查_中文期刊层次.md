# 核查：中文期刊层次与主管部门（一级指标）

核查日期：2026-10-08。核查人：cn-journal-checker。
范围：只核查期刊资质（主管主办、收录库、影响因子、分级目录），不评价论文内容质量。
规则：每条指标都给出实际访问的来源 URL；查不到写「未查到」，不推测。

## 0. 访问限制与数据来源性质（先说清楚）

- **CNKI 桌面版期刊导航页不可读**：`navi.cnki.net` 与 `kns.cnki.net` 均跳转到滑块人机验证（`/verify/home?captchaType=blockPuzzle`），无法直接读取。改用**手机知网期刊信息页**（`wap.cnki.net/touch/web/Journal/Info/<刊号>.html`）读取同一组字段（主办单位、收录历史版次、复合/综合影响因子）。该页面**不标注影响因子的统计年度**，故本核查只能写数值、不能写年份。
- **CSCD 官方查询系统不可读**：`sciencechina.cn` 返回 404、`www.csci.ac.cn` 返回 403、`sdb.csdl.ac.cn` 跨域跳转。改用**高校科技处转载的 CSCD 官方来源期刊目录 PDF**（原发布单位：中国科学院文献情报中心）。这属于转载件，已在来源栏注明。
- **中国科协分级目录总汇**：取自中国科协官网（`sj.cast.org.cn`）的 PDF 原件。
- 维普（cqvip）各页面返回 HTTP 412 反爬，未采用。

## 2. 判断问题：《制造技术与机床》与《自动化学报》是否同一层次？

**结论：不是同一层次。综合硬指标相差约 2 档（T1 对 T3）。**

只列可核查的客观依据：

| 可比项 | 《制造技术与机床》 | 《自动化学报》 | 差档 |
|---|---|---|---|
| EI 收录 | 未收录（官网 16 项收录清单无 EI；CNKI 无「EI工程」标识） | 收录（官网首页标识 EI；CNKI 标识「EI工程」） | 差 1 档（有/无） |
| CSCD | 不在 CSCD 任何库（含扩展库） | **CSCD 核心库**（连续两版） | 差 1 档（核心库/无） |
| 复合影响因子（CNKI） | 1.706 | 6.32 | 约 **3.7 倍** |
| 综合影响因子（CNKI） | 1.032 | 3.178 | 约 **3.1 倍** |
| 中国科协体系分级 | 机械工程领域 **T3** | 自动化领域 **A 类（T1 级）**；计算领域 **T1 类** | 差 **2 档** |
| 权威性表述（主办方官网） | 未使用「权威」类定位；荣誉多为广告/出版行业奖及优秀科技期刊奖 | 「信息与系统科学工程领域中文权威学术期刊」「中国科技期刊卓越行动计划领军期刊」 | 定性差距明显 |
| 主管层级 | 中国科学技术协会（全国学会口） | 中国科学院 | — |

**两者相同之处（不应夸大差距的部分）**：都属于《中文核心期刊要目总览》2023 年版（第10版）核心期刊；都属于中国科技核心期刊（中国科技论文统计源期刊）；都以机械/自动化工程为报道方向。所以《制造技术与机床》是「正规的中文核心 + 科技核心期刊」，只是**不是 EI、不是 CSCD、分级目录 Tier 更低**。

## 3. 「《制造技术与机床》能否承担综述的奠基性引用」

按「奠基性引用」的两种可能含义分别回答：

**（A）若指「以中文权威期刊的高水平综述作为领域框架来源」——不宜单独承担。**
可直接写进报告的依据：
1. 《自动化学报》有 **EI 收录 + CSCD 核心库**，《制造技术与机床》两项均无；这是两条独立的、非量纲性的硬门槛差距。
2. 分级目录上《自动化学报》为 **T1（A 类）**、《制造技术与机床》为 **T3**，相差 2 档。
3. 影响因子量级差 3 倍以上（复合 6.32 : 1.706；综合 3.178 : 1.032）。
4. **项目第一章现有的奠基性引用已经是《自动化学报》论文**：伍麟、郝鸿宇、宋友《基于计算机视觉的工业金属表面缺陷检测综述》，自动化学报 2024, 50(7): 1261−1283，DOI 10.16383/j.aas.c230039（见 [官网文章页](https://www.aas.net.cn/cn/article/doi/10.16383/j.aas.c230039) 与 [文献综述_完整初稿.md](文献综述_完整初稿.md) 第 27 行 [1]）。因此不需要用《制造技术与机床》去补这个位置。

**（B）若指「作为国内机械制造领域核心期刊的综述来源」——可以承担，但必须限定表述。**
可写为：「《制造技术与机床》为 2023 年版北大核心、中国科技核心期刊，属机械工程领域 T3 级期刊」；不能写成「权威期刊」「EI 期刊」「CSCD 收录期刊」。在项目现有材料中，它本来就被标注为**写法参考**（见 [文献综述_文献与写法依据.md](文献综述_文献与写法依据.md) 第 32 行与第 151 行），这个定位与核查结果一致。
