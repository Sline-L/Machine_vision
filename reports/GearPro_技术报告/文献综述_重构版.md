# 金属零件外观缺陷视觉检测研究进展与齿轮质检应用

## 1. 引言与综述范围

在高可靠性机械传动与精密制造装备中，关键回转构件的表面完整性（Surface Integrity）是决定其接触疲劳寿命、传动平稳性及整机服役安全的基础质量要素。金属零件在机加工、冲压锻造与热处理等工艺流转过程中，易引入微细裂纹、点蚀凹坑、划痕磕伤及局部材料缺损等微观形貌异常。此类外观缺陷若未能于制造出厂前有效检出，将在交变载荷与啮合冲击下诱发应力集中，进而加速微动磨损乃至导致早期疲劳断裂。传统人工目视抽检长期受制于检验员主观疲劳、尺度感知离散以及复杂曲面视界盲区，难以满足高节拍自动化产线对零缺陷全检的质量控制要求。自经典自动化光学检测（Automated Visual Inspection, AVI）框架确立感知成像、特征表征与几何公差的统一任务以来[1]，机器视觉与深度学习的快速演进显著拓展了工业复杂表面的缺陷识别效能[2]。

### 1.1 金属零件外观检测的需求与光学感知瓶颈

在离散制造流水线中，自动化视觉检测系统通过多源传感器阵列与图像算法，实现对零件表面的逐件连续筛查与质量全息追溯。现有关于工业缺陷检测的综述多从缺陷先验分布的完备性出发，将主流方法归纳为已知类别监督学习、弱监督/小样本学习以及无监督异常检测三大范式[2]。然而，算法模型的判别效能并非独立存在，其在工业物理场景下的性能表现根本上取决于底层光学成像系统所能捕获的有效信息熵。

金属工件表面的光学反射与微观几何形貌构成了视觉感知的首要物理瓶颈。金属基体通常呈现显著的双向反射分布函数（Bidirectional Reflectance Distribution Function, BRDF）非均匀性，切削、车削或磨削工艺更会在工件表面留下具有明显方向性的周期性微观微刀痕[3]。在常规明场照明下，加工纹理极易与浅层划痕产生高频混叠，而局域镜面强反射则会使光电传感器发生饱和溢出，导致暗弱缺陷信息彻底湮没于高光盲区[3,4]。Saiz 等[4]针对高反光金属构件的系统性研究表明，引入光度立体视觉（Photometric Stereo）以联合解算微观几何梯度、表面起伏与主曲率张量，相比单纯依赖二维灰度纹理能显著提高缺陷分割的鲁棒性。这表明，金属零件的外观检测本质上是“光学照明几何解耦—传感器高动态捕获—底层图像表征”协同作用的物理感知过程，脱离具体的物理成像条件去孤立评估后端模型指标往往缺乏工程指导意义。

### 1.2 齿轮外观检测的几何复杂性与科学边界

相较于平板钢材或规则轴类零件，齿轮工件的视觉质检面临着更为严苛的非连续几何曲面与动态成像挑战：
1. **复杂非欧几何与遮挡互反射**：齿轮表面由多组周向周期性分布的渐开线齿面、齿顶倒角、齿根过渡圆角及端面交织而成。齿面渐开线曲率的连续变化导致法线方向在小空间跨度内急剧偏转；尤其是齿根狭窄区域，极易形成严重的光学阴影遮挡与多重次生互反射，使传统单向结构光或漫射光场发生严重退化。
2. **多视角时空连续关联**：单个齿轮无法通过单幅视场完成全貌检测，必须依托回转机构带动工件自转，利用多相机协同实现全齿周向覆盖与逐齿扫描[5]。这种多视角连续采样机制使得单齿缺陷在序列图像中呈现出动态进出视场的特征，对时序图像间的去重关联与空间位置映射提出了硬性要求。
3. **任务科学边界界定**：本文聚焦于制造加工阶段**可见外观几何形貌与表面材质异常的自动化视觉识别及其向齿轮工件级质检判定的转化机制**。必须明确，工件合格判定不仅涉及外观视觉特征，还与齿向/齿形公差、跨棒距等精密几何尺寸计量密切相关；而构件的最终服役安全性更受内部金相组织、残余应力分布及材料力学性能制约。因此，内部探伤（如超声、X 射线计算机断层扫描）、啮合传动误差测试以及运行状态下的振动声学故障诊断与寿命预测均不纳入本综述范围。

### 1.3 综述核心问题与全篇技术脉络

为厘清从原始图像采集到最终工件级质量决策的全链条演进逻辑，本文以“**底层光学感知（看得见）—中层特征表征（分得清）—顶层系统决策（判得准）**”为主线，重点探讨并回答以下三个核心科学与工程问题：
- **表征机制与数据依赖**：各技术路线在不同历史阶段如何利用几何物理先验、端到端数据分布或正常模式先验构建判别边界？
- **物理与工况瓶颈突破**：面对金属高光互反射、微细尺度裂纹、视角敏感性及工业长尾少样本困境，现有方法在理论假设与网络拓扑上做出了哪些关键创新，其物理与计算代价为何？
- **实验基准向工程落地的映射**：学术公开数据集上的图像级评估指标（如 mAP、Pixel-AUROC）在何种条件下才能有效转化为面向独立新工件的漏检/误报代价评估与产线节拍适应性？

## 2. 视觉检测方法的历史演进与技术范式转向

工业表面视觉检测数十年的演进历程，其核心动力在于对**缺陷特征表达机制（由人工先验设计转向数据驱动自适应学习）**与**先验知识利用方式（由穷举已知缺陷样本转向刻画无缺陷正常模式流形）**的范式重构。早期方法依赖显式几何与纹理数学建模，随后卷积神经网络实现了深层语义与底层细节的自适应抽象，而无监督/自监督异常检测则开辟了应对工业开集（Open-set）未知异常的新路径。这三代范式分别对应着不同的先验假设与数据边界，在工业制造场景中呈现出互为补充、分层协同的演进特征。

### 2.1 规则与人工设计特征范式（显式规则与统计描述时代）

在深度学习普及之前，传统机器视觉检测主要依赖模式识别中的手工特征工程与显式决策规则。该范式首先通过空间域或频域变换将图像局部灰度梯度的剧烈扰动映射为可量化的统计特征向量，再经由设定几何阈值或浅层统计学习分类器完成缺陷判别。

在金属材料检测领域，纹理分析算子与尺度不变特征得到了广泛应用。例如，Song 和 Yan[6]针对热轧钢带表面复杂噪声，提出了一种基于完备局部二值模式（Completed Local Binary Patterns, CLBP）的鲁棒特征提取方法，通过将局部差分分解为符号与幅值分量，有效抑制了均匀光照波动对微观纹理分布的干扰；Liu 等[7]系统对比了尺度不变特征变换（SIFT）、加速稳健特征（SURF）与局部二值模式（LBP）在冷轧钢板缺陷表征上的分离度，并将其与极限学习机（Extreme Learning Machine, ELM）结合以满足产线实时分类需求。此类传统方法的优势在于**计算复杂度低、特征物理机理可解释性强、数学定义清晰**，在受控光学环境与固定几何构型下能够实现极高的执行速度。

然而，人工特征范式的有效性建立在“**成像环境严格稳定且缺陷对比度先验已知**”的强假设之上：
- **光照几何敏感性**：一旦视场内存在金属镜面高光反射、微小视角偏转或光源照度衰减，预设的差分模板与灰度共生直方图将发生严重畸变；
- **特征表达容量瓶颈**：同一种手工特征算子难以兼顾各向同性的麻坑点蚀、各向异性的微细划痕与非规则的材料缺损；
- **产线迁移适应性极差**：产线更换工件批次或新增缺陷类别时，工程人员必须推倒既有规则库，重新进行繁复的特征工程与阈值调优，极大制约了其在柔性制造产线中的广泛应用。

### 2.2 监督深度特征表征范式的演进与突破（端到端学习时代）

以 AlexNet、VGG 及 ResNet 为代表的深度卷积神经网络（CNN）打破了手工设计特征与分类器分离的传统架构，实现了从原始像素输入到高层判别语义的端到端特征自学习。卷积核通过多层级联的非线性映射，在网络浅层自发捕获边缘、纹理等高频空间基元，在深层抽象出表征全局结构与上下文拓扑的语义特征图，从而大幅增强了对复杂多变表面缺陷的特征泛化能力。

针对金属缺陷尺度的宽动态范围特性，多尺度特征融合网络成为提升表征容量的经典架构。Liu 等[8]提出的 ConCNN 采用不同感受野的多分支图像输入与多尺度卷积流，在网络内部实现局部细节纹理与全局上下文信息的显式融合。在公开钢材缺陷数据集（NEU-CLS）上的对照实验证实，多尺度并行特征提取能够显著缓解细长划痕与弥散斑块在下采样过程中的空间信息湮没问题，其分类准确率由单分支基线的 92.14% 提升至 98.89%[8]。

然而，监督学习特征的强大表征能力是以**大规模均衡标注数据与封闭集（Closed-set）假设**为前置条件的：
- **长尾与开集困境**：在实际精密加工中，合格品占据绝对主导（通常高于 99%），真实缺陷样本发生概率极低且形态开放未知，监督模型在面对未曾训练的新型缺陷形态时极易产生置信度虚高的误判；
- **特征泛化对数据分布的过拟合**：监督模型学到的高维流形边界高度绑定于训练集的照明拓扑与背景纹理分布，当面临未覆盖的材料表面微观粗糙度波动或装夹姿态变化时，其判别边界的稳定性缺乏理论保证；
- **像素级与实例级标注代价高昂**：对于细微裂纹等弱对比度目标，人工标注边界的离散性与主观偏差会直接引入标签噪声，削弱模型的精细化分割能力。

### 2.3 从已知模式判别到正常流形建模（无监督/自监督异常检测时代）

为彻底破解工业现场缺陷样本极度稀缺与未知异常无法穷举的固有矛盾，视觉检测范式在近年来发生了根本性跃迁——从“**学习并拟合已知缺陷类别分布**”转向“**刻画并包络无缺陷正常工件的特征流形**”。无监督/自监督异常检测（Anomaly Detection, AD）仅使用经确认的正常工件图像构建先验分布基准，通过度量测试样本与正常流形之间的几何/统计偏离程度实现异常判别与像素级定位。MVTec AD 工业异常基准数据集的建立[9]，规范化了图像级异常评分与像素级异常定位热图的定量评测协议，推动该范式成为精密制造质检的重要研究前沿。

在算法机理层面，正常流形建模演进出两大代表性技术路径：
1. **生成与重构误差路径**：以自编码器（Autoencoder, AE）和生成对抗网络（GAN）为代表，基于“模型仅能高质量重构正常先验分布”的假设，将输入图像与重构图像在像素空间或深层特征空间的残差图作为异常信号[9]。然而，由于卷积网络的泛化冗余，该路径常面临微小缺陷被“过度重构（Blurry / Identity Reconstruction）”而导致漏检，或高频复杂背景纹理重构保真度不足而诱发大面积误报的物理瓶颈。
2. **预训练特征嵌入与近邻分布建模路径**：该路径利用在大规模通用数据集（如 ImageNet）上预训练的深度网络提取局部特征补丁（Patch Tokens），直接在特征空间建模正常分布。PaDiM[17]通过在特征图各空间网格位置拟合多元高斯分布，利用马氏距离显式刻画位置先验与通道相关性；PatchCore[10]则进一步打破了刚性网格对齐约束，利用贪心 Coreset 算法构建高代表性的局部特征记忆库（Memory Bank），以测试特征到记忆库的最短欧氏距离作为异常度量准则。Roth 等[10]的研究表明，局部特征近邻检索不仅在工业基准上实现了接近全召回的高性能定位，而且极大降低了非参数化模型的内存开销与检索延迟。

然而，正常模式建模范式同样具备严格的物理与统计适用边界：
- **正常形貌分布覆盖假设**：该范式严格假设训练集能够充分遍历工件在正常生产状态下的所有合法波动（包括刀痕各向异性、微观反光漂移、装夹位姿微动等）。若齿轮由于旋转角度偏差导致齿廓在成像视场中发生局部几何畸变，未被记忆库覆盖的正常位姿将直接被误判为结构异常[17]；
- **语义与尺寸可解释性缺失**：异常检测输出的连续标量热图仅代表与正常流形的离散偏离度，无法直接解析缺陷的具体物理类别、几何尺寸（长度/深度）或质量等级，工程落地中仍须级联几何标定与后处理规则链条。
