### 2.1 从范文提炼的写作方式

**先定义比较对象。** 在介绍分类研究前交代它预测的是正常／缺陷，还是已有缺陷类别。介绍多尺度方法时交代它改变的是输入、特征还是输出层。这样读者能够理解研究之间的关系。

**用研究解释问题。** 作者姓名和方法名称服务于论述，不作为每段的固定开头。围绕同一问题选择两三项工作，说明机制差异；原文确有继承关系时才使用“在其基础上改进”。

**结果和条件一起出现。** 只保留支持比较的数字。精度应带任务和数据，速度应带硬件。不同研究之间不根据一个数字直接排优劣。

**评价落到具体证据。** 可以指出未测试正常样本、只按图像随机划分或没有独立的小缺陷分组实验；不能据此直接断言方法不适用于工厂。

**小结形成认识。** 小结回答方法如何选择、哪些条件仍需验证，避免重复“本文介绍了……”。未来方向承接前文限制，不单纯罗列新模型。

### 2.2 语言规范

采用简洁中文期刊综述语气。常用“研究采用”“结果表明”“相比之下”“仍需验证”等准确表达，不刻意增加口语，也不靠抽象词提高正式程度。

| 容易出现的问题 | 修改方向 |
|---|---|
| 大段“随着技术不断发展”“具有广阔前景” | 直接说明检测任务和困难 |
| “赋能、全面突破、强大能力、重大提升” | 写清具体变化、对照及指标 |
| 每篇都写“某某提出……达到……但仍存在不足” | 按问题分组，交替采用解释、实例和比较 |
| “泛化能力差”“无法满足工业要求” | 说明缺少什么验证，或引用具体失败实验 |
| “提高3.9%”而差值来自两个百分比 | 根据原始数值写“提高3.9个百分点” |
| 将分类、目标检测、异常检测列为互斥类别 | 分开输出任务与学习设定 |

不通过机械替换所有连接词来消除模板感。每段的因果、比较或限定关系应由研究内容决定。正式稿保留常规编号引用；阅读程度、核查状态和段落作用只出现在工作材料中。

## 3. 两节试稿的文献提取

试稿共使用六项研究。图像分类涉及三项；小缺陷相关核查涉及FPN、TDD-Net、MSFE-YOLO及ConCNN，其中ConCNN跨节提供分类任务的多尺度对照。全文可取得不等于全文每段已精读，以下明确记录实际使用范围。

### 3.1 Liu等：ConCNN，2020

来源：[期刊全文](https://www.mdpi.com/1996-1944/13/20/4629)，DOI：10.3390/ma13204629；[PubMed题录](https://pubmed.ncbi.nlm.nih.gov/33081388/)。已读方法、实验、结果和结论，核对PDF表2。

| 提取项 | 记录 |
|---|---|
| 对象／输出 | 钢表面图像的六类缺陷分类；NEU-CLS不含独立正常类别 |
| 方法 | 不同输入尺度的并行卷积网络，融合特征后分类 |
| 数据／划分 | 1800张；20%、50%、80%图像随机训练比例；重复20次；独立工件与批次划分未报告 |
| 对照 | 包含同文单分支ConCNN-single；表2给出准确率与CPU/GPU时延 |
| 作者结果 | 20%训练比例时双分支准确率98.89%，单分支92.14%；GPU时延5.58与3.08 ms |
| 硬件 | GTX 1080 Ti；时延定义为图像输入到模型结果，不是整机节拍 |
| 本文分析 | 支持该设置下多尺度分类的收益与代价；不能据此说明正常件误报或齿轮整机效果 |

### 3.2 Arikan等：SurfNet，2019

来源：[arXiv题录](https://arxiv.org/abs/1904.04671)、[公开PDF](https://arxiv.org/pdf/1904.04671)。采用预印本，未核实正式发表版。已读测试处理、网络比较、数据与结果章节。

| 提取项 | 记录 |
|---|---|
| 场景／输出 | 多材质工业表面二分类，同时另做NEU缺陷类别实验 |
| 方法 | 比较SurfNet、快速模型FastInf和多尺度模型MultiVis |
| 数据／标签 | 私有表面数据含缺陷和无缺陷；测试图像由专家先裁取相关区域；工件数未报告 |
| 划分与对照 | NEU使用10折交叉验证；私有测试区域裁剪条件须与结果一起解释 |
| 结果／硬件 | 包含准确率和逐图推理时间；使用GTX 1080 Ti；本试稿不引入其数值 |
| 本文分析 | 二分类与缺陷类别分类需分开；已裁剪区域上的性能不代表任意整幅工件图像的效果 |

### 3.3 Nagy与Czúni：预训练特征与随机化分类器，2022

来源：[期刊全文](https://www.mdpi.com/2076-3417/12/8/3967)，DOI：10.3390/app12083967。已读方法、两项基准及少样本增量实验。

| 提取项 | 记录 |
|---|---|
| 对象／标签 | NEU六类、X-SSD七类钢表面缺陷；不是正常／缺陷二分类 |
| 方法 | 使用EfficientNet-B7特征，并为新增类别比较随机化分类器等方案 |
| 数据与划分 | NEU为1800张、图像随机80%训练／20%测试；X-SSD为1360张；增量实验另行划分并重复抽样 |
| 对照 | 已有类别识别和新增类别少样本适应分开评价，比较多种分类与微调方案 |
| 部署条件 | 报告工作站环境；未报告完整齿轮检测流程 |
| 本文分析 | 有助于区别“已有类别识别好”与“新增类别容易适应”；不据此推断对未知缺陷的自动识别能力 |

### 3.4 Lin等：FPN，2017

来源：[CVF正式论文PDF](https://openaccess.thecvf.com/content_cvpr_2017/papers/Lin_Feature_Pyramid_Networks_CVPR_2017_paper.pdf)。已读结构、检测对照和小目标相关实验。

| 提取项 | 记录 |
|---|---|
| 场景 | COCO通用目标检测，不是金属零件研究 |
| 方法 | 自顶向下路径和横向连接，将深层语义与较高分辨率特征结合 |
| 对照 | 分析连接结构及不同层级的作用，并报告不同尺度目标的评价 |
| 本文分析 | 用于解释多尺度机制；不将COCO结果转写为工业小缺陷收益 |

### 3.5 Ding等：TDD-Net，2019

来源：[作者机构公开录用稿](https://robotics.pkusz.edu.cn/static/papers/CAAI2019-dingrunwei.pdf)；[正式题录](https://doi.org/10.1049/trit.2019.0019)，CAAI Transactions on Intelligence Technology，4(2)：110–116。已读结构和实验；实际全文是录用稿，题录采用正式版。

| 提取项 | 记录 |
|---|---|
| 对象／标签 | PCB六类缺陷、框标签；用于小缺陷机制对照，不当作金属齿轮应用 |
| 方法 | 调整锚框、融合多层特征、在线困难样本挖掘 |
| 数据／划分 | 693张原图经增强和切片；原图是否先分组再增强未交代清楚；不能直接断言泄漏 |
| 对照 | 录用稿表4按顺序增加组件；加入多尺度融合后mAP@0.5由96.44%升至98.02% |
| 记录问题 | 数据段落测试切片数2508，组件表写2134，需正式全文或代码进一步核对；不在试稿使用该数量 |
| 本文分析 | 收益依赖已调整锚框的前置配置，不作为多尺度模块在所有场景的独立增益 |

### 3.6 Su等：MSFE-YOLO，2026

来源：[期刊全文](https://www.mdpi.com/1424-8220/26/8/2311)，DOI：10.3390/s26082311。已读结构、数据、实验设置和对照，核对PDF表3、表4。

| 提取项 | 记录 |
|---|---|
| 对象／标签 | NEU-DET与GC10-DET钢表面框检测 |
| 方法 | 多尺度频域特征、缺陷相关注意力、自适应融合 |
| 划分／输入 | 两数据集均按7:1:2划分；输入640×640；工件及批次独立性未报告 |
| 对照 | 有单组件、组合组件及完整模型对照；表3、表4的基线与最终结果一致 |
| 结果 | NEU-DET：mAP@0.5为78.1%→79.8%；mAP@0.5:0.95为46.2%→45.8% |

| 本文分析 | 宽松匹配指标、严格匹配指标和速度变化不同；没有依据写成全面改善或全部小缺陷均获益 |

### 9.3 第六、七章的证据性质

第六章不新增未经验证的性能主张，而是把第三至第五章确认的限制改写为可检验方向：先说明成像覆盖、独立工件泛化、标注与计算负担或工件级评价的缺口，再给出数据记录、拆分或实验方案。第七章只综合全文，不引入新文献和新事实。

以下边界继续保留：

- 齿轮直接应用证据主要来自Allam等的齿部损伤场景，不代表全部齿轮缺陷与规格。
- 钢带、PCB、换向器及通用异常数据只支持方法机制或评价思路，不写成齿轮实测效果。
- 跨批次、跨规格和持续运行仍是建议的验证方向，当前正文不声称已有证据证明其性能。
- 融合规则、阈值和校准方法均需在独立验证数据上确定；正文未给出未经实验的最优组合。
