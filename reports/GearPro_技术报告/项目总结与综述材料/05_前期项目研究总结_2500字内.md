# GearPro 齿轮外观缺陷检测系统：前期项目研究总结

---

## 一、 选题背景

齿轮是机械装备的核心传动构件，表面微细划痕与局部齿部缺损（碰伤、崩齿）极易在交变载荷下诱发应力集中与断齿损坏。车间传统人工目检存在易疲劳、尺度不一和漏检等痛点，难以满足现代全检需求。

本项目源于我们在大学本科修读《数字图像处理》、《机器视觉》及《传感器技术》等专业课程时建立的学术兴趣。在金工实习深入车间参观时，我们目睹了工人用放大镜肉眼质检的疲劳与困扰，体会到视觉检测替代人眼的必要性。结合团队在 Python/C++ 编程、PyTorch 深度学习与 OpenCV 图像处理上的实践积累，我们自主确立了“基于机器视觉的齿轮外观缺陷自动检测系统”攻关方向。

---

## 二、 团队与导师

本项目由 3 名大三工科本科生组成跨专业协作团队：
- **软件与算法负责人（本人）**：统筹算法方案设计，负责齿轮数据集构建、模型训练与加权融合，以及上位机检测软件与 Web 监控界面的开发；
- **机械结构与打光成员**：负责第一代实验台架结构设计、旋转夹具加工装配，以及不同工业光源的打光试验选型；
- **电气控制与嵌入式成员**：负责基于 STM32 的微控制器开发、步进自转驱动与气动分拣推杆的串口协议联调。

团队分工明确、配合默契。指导教师在光电精密检测领域具有深厚科研与工程经验。导师定期审读实验记录与技术报告，针对“单图与工件级质检的区别”、“模型融合必要性”及“独立测试集划分”等关键问题进行把关指导，确保了项目的科学推进。

## 三、 创新与特色

### 1. 针对划痕与缺损的“分别建模与多模型加权融合”方法
通用目标检测模型难以兼顾微细划痕（线状弱对比）与齿部缺损（块状几何破坏）的形态差异。本项目打破单一模型局限，提出按缺陷类别分别建模策略：
- **划痕子系统**：在 YOLO 模型中引入保留浅层高分辨率特征的 **P2 检测层**，有效捕获仅数个像素宽的微细划痕；同时融合 EfficientNet 与 ResNet 分类模型提取全局语义，经温度缩放校准后加权融合，实现“分类抗局域噪声、检测抗全局漏检”；
- **齿部缺损子系统**：采用原始 YOLO 与分类模型结合，通过基于“或规则”的决策级合并，显著提升复杂工业背景下的综合检出能力。

### 2. 上下双相机多视角配合连续帧去重的工程设计
针对齿轮立体渐开线曲面与齿根阴影遮挡难题，设计了上下双相机协同拍照方案：上方相机垂直覆盖端面与齿顶，侧方相机斜向覆盖齿面与齿根，配合漫射光源有效压制了金属镜面反光；同时在软件中引入连续多帧时序滑动窗口判定机制，只有在旋转中连续检出才触发报警，有效过滤了单帧偶发反光带来的误报。

### 3. 低成本、轻量化且面向实际落地的边缘端架构
软硬件方案面向中小型机械制造产线实际需求定制，以 NVIDIA Jetson NX 嵌入式工控机作为边缘计算核心，通过轻量级网络设计与串口指令直接联动 STM32 机构，形成了集“自动取流、ROI定位、缺陷推理、界面显示、气动分拣”于一体的低成本闭环质检原型。

## 四、 进展与成果

经过前期扎实的实验探索与软硬件开发，项目已完成从实验室算法设计到第一代台架联调的阶段性任务，具体进展与成果如下：

### 1. 具体实施进度与技术演进历程
- **多视角自建数据集构建**：针对缺乏齿轮外观缺陷公开数据的现状，团队自行采购定制 50 个真实齿轮（10 正常、15 划痕、15 侧部缺损、10 齿角缺损），利用台架工业相机采集多视角图像；人工标注可见缺陷框，并对边界模糊目标标注 `difficult=1`，在训练时予以剔除以保证模型收敛稳定性。
- **算法模型的三轮迭代优化**：
  - *V3 阶段*：对比了图像分类（整图判断）与目标检测（框级定位）的性能差异，明确了两者评价指标与用途的不同；
  - *V4 阶段*：尝试训练两类缺陷合一的统一分类模型，发现统一模型严重漏检划痕，且增加模型数量无法解决划痕漏检，促使团队反思并调整路线；
  - *V5 阶段*：确立了当前“分别建模 + 分数加权融合 + 决策级或规则合并”的最终技术路线。
- **软硬件台架集成与系统联调**：搭建完成了包含上下双工业相机、漫射光源、步进自转机构、Jetson NX 与 STM32 控制器的第一代实验台架，完成了相机 SDK 取流与分拣串口协议的联调。

### 2. 已取得的阶段性创新成果
1. **算法性能实现实质性突破**：在 150 张离线测试集（含 71 张缺陷图、79 张无目标缺陷图）上，当前 V5 融合方案实现了 **88.73% 的缺陷召回率与 22.78% 的误报率**。相比早期统一分类基线，在相同测试集上**正确检出数净增加 9 张图片，误报数减少 15 张图片，误报率显著下降 18.99 个百分点**，验证了分别建模与特征融合策略的有效性。
2. **自主开发了成套可视化检测与监控软件**：使用 Python/C++ 开发了上位机质检软件，实现相机多线程取流、齿轮 ROI 自动定位裁切、多模型并发推理、温度缩放校准与串口指令触发；同时开发了轻量级 Web 交互监控界面，能实时渲染齿轮图像、红框标出缺陷坐标、展示置信度得分及 PASS/REJECT 状态，为产线工人提供了直观高效的辅助复核工具。
3. **沉淀了规范翔实的全套工程技术文档**：形成了严谨规范的技术文档体系，包括系统梳理方案演进的《GearPro 技术报告》、符合大三学生视角的 5000 字《文献综述重写版》、直面短板的《项目存在的问题及拟采取的解决方案》以及《文献综述写作规范与指南》，为后续新工件独立盲测与产线部署打下了坚实基础。

## 五、 结语

前期研究充分验证了 GearPro 系统技术路线的科学性与可行性。下一阶段，团队将在导师指导下，重点推进新批次物理齿轮的独立盲测、连续多帧滑动窗口时序去重算法落地，以及 Jetson NX 边缘端的 TensorRT 量化加速实测，力争将系统打造为兼具理论支撑与工业实用价值的智能质检成果。
