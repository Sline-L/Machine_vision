# 《文献综述_重写版_5000字》引用与数据核验报告

核验日期：2026-10-09。对象：[原稿](文献综述_重写版_5000字.md)。行号按核验时169行版本。核验覆盖参考文献全部24条（编号1–22、24、25），其中正文使用22条；[12]、[21]只在文末列出，[23]缺号。未修改原稿。

## 结论

没有查出可以认定为“凭空编造、论文不存在”的条目。主要定量结果也确有原文依据，包括ConCNN的98.89%、Allam的30/30和34/100，以及MSFE-YOLO的79.8%和89.3 FPS。主要问题是**真实论文被错误转述：改写网络结构、混淆输入信息、虚构论文没有做过的标注处理实验，以及把工程建议写成论文已证明的结论**。以下把明确错误、证据不足和真实数据分别列出。

核验依据为出版方、CVF、arXiv、JMLR和作者机构原文；部分历史期刊文献仅取得题录或摘要，详见完整清单。短英文引文用于定位，中文解释为核验者转述。每篇英文摘录合计控制在25词以内。页面编号指下列链接版本，可能与其他预印本排版不同。

## 一、明确错误和严重失真

### 1. [4] Saiz：把作者网络写成U-Net，把梯度幅值写成高度图

原稿64行写“高低起伏图和曲率图……送入U-Net”。原文§2.1、§2.2和§3.6显示：输入为texture、range、curvature；range在本文被定义为图像梯度幅值，不能直接称为经三维重建得到的高度图。作者采用自定义分割网络，U-Net是对比对象，表8将两者分列。

原文片段：

> “Range images: Computed as the image gradient magnitude.”
>
> “we compared our approach with two well-known segmentation networks: DFANet [26] and UNet [27].”

[出版方PDF，§2.1–2.2及表8](https://mdpi-res.com/d_attachment/sensors/sensors-22-00882/article_deploy/sensors-22-00882-v2.pdf)；[可读全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8838491/)。

66行“模型能分辨发白区域没有物理凹陷”也不是论文直接验证的因果解释。实验确实支持组合输入改善结果，不能据此声称网络显式判断物理凹陷。

建议替换：“作者将纹理、梯度幅值和曲率信息组合成RGB输入，送入自定义分割网络；与仅用纹理的输入相比，多种材料的检测结果有所改善。”

### 2. [5] Allam：单一齿部损伤被扩写成缺损与划痕联合识别

原稿76行写“使用Faster R-CNN识别缺损与划痕”。原文§4.3明确只训练一个前景类别damaged teeth defects，没有划痕作为独立类别的联合识别实验。

> “For training the network, we considered only one foreground class (i.e., damaged teeth defects), and used a batch size of four images.”

[原论文PDF，§4.1–4.3、§5.2–5.3](https://mdpi-res.com/d_attachment/sensors/sensors-21-08480/article_deploy/sensors-21-08480.pdf)。

“上下双相机，分别拍摄端面和侧面”也比原文更具体：作者描述的是检测腔相对两端的两台相机及旋转夹持机构，不能把GearPro的安装位置当作原论文布局。扫描过程逐齿转位拍照，共22或26个齿；作者把连续运动扫描列为优化方向。建议写“两台相机配合旋转夹持机构扫描齿部，检测齿部损伤”。

### 3. [8] ConCNN：晚期双分支融合被写成浅层不同感受野融合

原稿71行“不同感受野的分支通道，在浅层同时提取……”不准确。原文§4.2及图4采用两路同构CNN，输入尺寸分别为200×200、400×400，各自经过卷积块和全连接层，再拼接两个特征向量完成六分类。

> “Both of CNN-1 and CNN-2 have the same structure and components but with different dimensions of input images.”
>
> “these two vectors are concatenated”

[原论文PDF，§4.2、§5.1及表2](https://mdpi-res.com/d_attachment/materials/materials-13-04629/article_deploy/materials-13-04629.pdf)。

每类60张训练图、98.89%与92.14%、差6.75个百分点都是真实的。但分类准确率不能证明“浅层高分辨率特征”是唯一原因，更不能直接证明齿轮微划痕定位或YOLO增加P2层有效。建议保留数据，改为“两种输入尺度的双CNN特征融合改善了该钢材数据集上的分类结果”。

### 4. [16] Tabernik：“每批1:1”与实际训练设置不符

原稿87行称“每批次按1:1放入正常图和缺陷图”。原论文训练batch size为1，按迭代交替抽取正、负样本，实现跨迭代的平衡采样。一个批次只有一张图，不能同时放入两类各半。应改为“正负样本交替采样，使训练迭代总体保持平衡”。

[作者机构原论文PDF，训练设置及采样实验](https://data.vicos.si/publications/tabernik2020segmentation-based.pdf)；[正式发表记录](https://doi.org/10.1007/s10845-019-01476-x)。相关原文片段与其他标注证据见本报告完整清单。

### 5. [16] Tabernik：“证明剔除difficult框有助于稳定训练”没有原文依据

原稿117行明确归因于Tabernik；89行也把“暂时剔除模糊样本”写成能获得可靠模型的途径。论文研究标注精度、少量缺陷样本及采样方式，没有报告剔除difficult框的实验。这是本稿中最应删除的“论文已经证明”式结论。

论文中困难缺陷的讨论是在分析极小、难以识别的漏检案例，不等于提出删除它们的训练策略。删除困难样本还会改变评估覆盖范围，不能由上述实验得出“同样稳定可靠”。建议删除该归因；若这是GearPro自己的处理策略，需要另给项目对照实验。

### 6. [17] PaDiM：高斯分布模型被混写成最近邻特征库

原稿53行将PaDiM与PatchCore统一写成“局部特征库，通过最短距离寻找异常”。PaDiM对每个空间位置拟合多元高斯分布，用马氏距离计算异常分数；PatchCore才是记忆库及最近邻距离。

> “Each patch position is described by a multivariate Gaussian distribution”
>
> “we use the Mahalanobis distance”

[PaDiM原文，§III-B、III-C](https://arxiv.org/html/2011.08785)；[正式会议论文](https://doi.org/10.1007/978-3-030-68799-1_35)。建议分别介绍两者，而不是将全部异常检测算法等同于特征库检索。

## 二、证据不足、过度归因与应收窄的表述

| 原稿位置 | 问题 | 核验判断与修正方向 |
|---|---|---|
| 12行“浅划痕、齿部缺损是发生最多的两类” | 没有频率统计或引用 | 改成“本文关注的两类”，除非提供实际产线统计。 |
| 19–21行引用[3]解释渐开线齿面、齿根阴影、互反射 | [3]对象是平板钢材 | 可作钢材缺陷检测背景，不能作为齿轮特有光学机理的直接证据。 |
| 40、102行“传统方法对光照极度敏感、稍变就失效” | 对整类方法作绝对概括 | [6]研究抗噪及灰度/照明变化鲁棒性；[7]也在比较具体特征。改成“部分规则对成像条件依赖较强，性能需按具体方法评估”。 |
| 44、103行分类模型“模型小、速度极快、易漏微小划痕” | 没有统一成立的实验 | [8][11]支持具体分类方法，不能代表所有ResNet/EfficientNet，也没有齿轮微划痕漏检率对照。 |
| 45行“目标检测工业界最普遍”、46行“分割很难推广” | 引用模型奠基论文不能证明应用普及率 | 删除排名与推广程度的绝对表述，保留输出和标注需求说明。 |
| 51行“正常合格品>99%”归[9] | 未找到普适产线统计 | MVTec AD是基准数据集，不是工厂总体合格率调查。删除>99%，改为“许多场景缺陷样本较少”。 |
| 66行[18]“消除反光” | 将改善说成完全消除 | 支持多角度照明及混合输入改善检测，不保证任意零件、缺陷、反光条件均消除。 |
| 73行[19]“频域计算使速度下降” | 将整模型变化只归因于一个部分 | 最终模型同时增加MSFC、C2MSDA、AFFE，89.3 FPS是整体结果，不能只归因频域计算。 |
| 73、113行[8][20]“增加P2层能提升检出率” | 工程假设写成实证 | ConCNN是分类研究；FPN是通用目标检测。应写“可尝试，并以齿轮对照实验验证”。 |
| 87行“粗框与精细标注几乎没有差别” | 泛化过度 | [16]有多种标注精度实验；成立范围是其裂纹数据、模型与图像级判定，不保证一般定位/面积精度相当。 |
| 89行[22]“接近全精细标注的检测精度” | 指标含义未交代 | 主要是图像级缺陷识别AP，不能自动换成像素级定位精度或尺寸测量精度。 |
| 115行“保证不漏检同时压误报” | 从有限测试外推保证 | [5]仅在30个测试坏件上无漏检；提高连续帧数已经产生漏检，应改为需独立验证的权衡。 |
| 117行[24]直接提醒同齿轮视角不能混入训练/测试 | 具体结论归错来源 | [24]讨论模型选择过拟合与评价偏差；[16]才有按物理工件分折的直接案例。 |
| 117行[25]提醒产线复核负担 | 合理工程推论，非原研究场景 | [25]讨论不平衡分类的PR/ROC解释，不是齿轮产线人工负担实验。 |

上述表中的“未提供证据”不等于物理上必然错误；问题是原稿将未验证的判断放在真实引文后，使读者误以为有论文实证。

## 五、标注实验与工件划分的准确边界

[16]在PDF“Required precision of the annotation”及图8–9中，普通框最佳图像级AP约98.7%、3次误分类；旋转粗框约99.7%、2次误分类；精细标注最佳约99.9%、1次误分类。这支持“在该数据和判定任务下，粗标注已取得接近精标注的结果”，不能写成轮廓/面积测量也几乎无差别。数据集部分为PDF第6页，训练与工件分折为第7页，标注实验为第9页，困难缺陷讨论为第12页（arXiv版本）。[Tabernik原文](https://arxiv.org/pdf/1903.08536)。

[22]在KolektorSDD上加入5张有分割标签的正样本，图像级AP由93.4%提高到99.1%，全监督为100%；在更复杂的KolektorSDD2上，16张分割正样本约83.2%，全监督约95.4%。原稿只说“少量精标接近全标”会掩盖后者的差距，应限定到具体实验。见§5.2图7、§5.3图9。[Božič原文](https://arxiv.org/pdf/2104.06064)。

工件独立划分可以直接引用[16]“Performance metrics”：三折交叉验证把同一物理工件的所有图像放到同一fold。[24]可以补充说明模型选择和最终性能评价为什么应保持独立，但不能将其写成关于齿轮多角度拍照的原始研究。

## 六、建议优先处理

1. 删除两处“Tabernik证明剔除difficult框”的归因；将batch=1、交替采样写准确。
2. 改正Saiz的网络和range信息、Allam的检测类别、ConCNN的融合位置、PaDiM的距离模型。
3. 保留已经核实的数值，补实验条件和指标层级，尤其避免用图像分类AP替代分割精度、用30个测试坏件零漏检替代产线保证。
4. 删除未经来源支持的“>99%”“发生最多”“工业界最普遍”等统计或排名；把P2层、加权融合、剔除模糊样本写成待验证项目方案。
5. 将工件分组实例归于[16]，整理[12][21]未引用和[23]缺号。若保留[12][21]，应在正文明确说明它们支持什么。
