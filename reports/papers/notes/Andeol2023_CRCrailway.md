# Andéol 2023 共形预测/共形风险控制用于铁路信号灯检测
- 完整引用：Léo Andéol, Thomas Fel, Florence de Grancey, Luca Mossina. Confident Object Detection via Conformal Prediction and Conformal Risk Control: an Application to Railway Signaling. arXiv:2304.06052v2 [cs.LG], 17 Apr 2023。（PDF首页只有arXiv版；正式发表信息取自其他PDF的引用：Proc. 12th Symposium on Conformal and Probabilistic Prediction with Applications (COPA), PMLR vol. 204, pp. 36-55, 2023，见2505.24038参考文献[15]与2504.17721参考文献[19]；PDF本身首页未写，此处标注为"间接来源"。）
- 来源核实：本地 OA_arXiv/2304.06052.pdf，21页；首页版本 v2，日期 17 Apr 2023；"Editor: Editor's name"占位符说明是预印排版稿。与已知元数据无冲突。
- 阅读深度：全文（摘要、第1-6节、全部表1-6、参考文献；无附录）。
- 一句话：在自建法国铁路信号灯数据集上，比较逐框共形预测（CP）与逐图像共形风险控制（CRC），CRC 能控制"漏检框比例/漏检像素比例"的期望，但需要基础检测器在每张图上至少有预测框。
- 问题设定：输入图像，输出带边距的预测框。数据需 i.i.d./可交换（第3.1、3.2节）；只用 split CP（校准集与测试集分离）。检测器预训练或微调。数据集3414张图（41段视频，每段约83帧，隔5秒取帧避免时间相关），第2节，表1。
- 方法：(1) 逐框 CP：用匈牙利匹配把预测框配真值框，对每个匹配上的框算坐标残差（additive 加性/multiplicative 乘性），四个坐标用 Bonferroni（α/4）或本文提出的 max 分数（取四个坐标残差最大值，一个分位数）；保证只对"匹配上的真阳性"成立（第4.1节原文强调）。(2) 逐图像 CRC：定义损失 L_box（未被完全覆盖的真值框比例）与 L_pixel（真值框未被覆盖面积的平均比例），用 CRC 公式 λ̂=inf{λ: n/(n+1)·R_n(λ)+B/(n+1) ≤ α} 选一个全局边距 λ（第3.3、4.2节，式(3)(4)(16)(17)）。无真值框的图损失为0（式16、17）。
- 保证 / 结论：CP：P(Y∈C(X)) ≥ 1-α（式2，边际、对校准集与测试点联合平均）。CRC：E[ℓ(C(X_{n+1}),Y_{n+1})] ≤ α（式3），原文注明比 split CP 的界松：1-α ≤ P ≤ 1-α+2B/(n+1)（第3.3.1节）。均为"期望/边际"保证，不是以 1-δ 概率成立的校准条件保证；单一参数 λ（逐框/逐图像边距），无两阈值联合校准。第6节结论称"CP 单独不太可能达到足够低的风险水平"。
- 实验：YOLOv5m、DETR-ResNet50、DiffusionDet，预训练 vs 微调；α=0.1，objectness 阈值0.3，IoU 阈值0.3（第5.1节）。预训练设定1914校准/1500测试（测试1974框）；微调设定1414训练/1000校准/1000测试（测试1022框）。表2 AP@IoU0.3：预训练 YOLOv5m 0.23、DETR 0.29、DiffusionDet 0.45；微调 YOLOv5m 0.36、DETR 0.42。表3/5 为 stretch（框面积放大倍数），如微调 YOLOv5m 逐图像 Hausdorff 25.96。表4/6 为覆盖率/风险。关键：表5、表6中预训练 YOLOv5m/DETR 以及部分DiffusionDet CRC 项为"--"，原因是"某些图上没有预测框，无论 λ 多大该图损失恒为1，式4无解"（第5.3.2节）。表6 内容文本抽取错位，我未能逐格对应到模型；其中出现风险 0.09-0.12 和覆盖 0.87-0.91 的数值（有一行 0.12/0.87，可能略超目标0.10，但未能确认对应哪个模型，见疑点）。
- 局限：作者承认：(a) CP 只对真阳性；(b) 若基础模型漏掉整张图上的目标，图像级风险无法达到（第5.4节）；(c) 数据可交换假设对数据流长期不成立（第6节）；(d) 数据集小、模型较弱。我看出的：无硬件部署、无量化、无级联；损失只管漏检不管误报（第4.2节原文："do not consider the false positive rate"）；无高概率（1-δ）版本，只有期望。
- 和我们的关系：背景/需区别。(1) 它是"期望风险 + 逐框/逐像素 + 单检测器"，我们的是"零件级漏检率 ≤ε、概率 ≥1-δ（LTT）+ 两阈值 + 两级级联"。(2) 它暴露的"检测器无输出时损失恒为1、λ无解"问题，对我们有启发：我们的 t1/t2 方案里门控分类器总有输出，但要定义"整个零件无缺陷"时的损失（此文式16/17对无真值图赋0）。(3) 无部署验证。（我的判断）可作为"CRC 用于检测"的引用，不构成对我们声明(a)的反例。
- 可引用的句子：CP/CRC 为 distribution-free、non-asymptotic、model-agnostic，且无需重训（第1节）；图像级 CRC 把风险定义为"未覆盖真值框的比例"（第4.2.1节）；CRC 保证为期望意义，界比 split CP 松 2B/(n+1)（第3.3.1节）；"conformalization is not a substitute for careful training"（第5.4节）。
- 疑点：表6文本抽取乱序，未栅格化核对；"AI and Ethics 4(1):157-161, 2024"（2505.24038参考文献[16]）是同组更早工作"Conformal prediction for trustworthy detection of railway signals"，与本文不同，勿混。正式COPA页码仅来自他文引用，需到PMLR页面核实。
