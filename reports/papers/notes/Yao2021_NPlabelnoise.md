# Yao, Rava, Tong, James 2021 标签噪声下的 NP 伞形算法
- 完整引用：Shunan Yao, Bradley Rava, Xin Tong, Gareth James. "Asymmetric error control under imperfect supervision: a label-noise-adjusted Neyman-Pearson umbrella algorithm". arXiv:2112.00314v1 [stat.ML], 1 Dec 2021（PDF标 December 2, 2021）。刊名、卷期页、DOI：原文未见（预印本）。
- 来源核实：本地 OA_arXiv/2112.00314.pdf，50页；首页为 arXiv v1 戳，与文件名一致。
- 阅读深度：正文第1-27页（引言、模型、方法、理论 4.1-4.3 的陈述、数值分析、讨论）全文读完；附录只读了 D.1 的 Simulation 7、8（Table 13、14）和 D.2 CIFAR10 开头，定理证明（附录 F）未读。
- 一句话：当训练标签带类条件噪声时，直接用原版伞形算法仍能控制"真实标签"下的 I 型误差，但会很保守；若专家提供噪声程度的下界，可用校正项取更小的顺序统计量，既控制 I 型误差又降低 II 型误差。
- 问题设定：只能观察 (X, Y~)，Y 是真实标签、Y~ 是被污染的标签；类0为被保护类。Assumption 1（类条件噪声，第5页）：P~0 = m0 P0 + (1-m0) P1，P~1 = m1 P0 + (1-m1) P1，m0 > m1；m0、m1 可未知，但专家给出已知常数 m0# >= m0、m1# <= m1（即噪声程度的"下界/低估"；符号在文本提取中丢失，我对照第6页页面图像确认；与第7页"m0=1, m1=0 对应无噪声"一致）。Assumption 2：n >= ceil(log delta / log(1-alpha))（第14页）。Assumption 3：在污染数据上训练的打分函数方向仍正确（F~0 > F~1，概率 >= 1-eps1(nb)）。Assumption 4：密度存在且有界等技术条件。样本方案：污染类0样本分三份（训练、阈值候选、校正），污染类1样本分两份。
- 方法：先看原算法在污染数据上的保证：Proposition 1（第13-14页）给出对"污染 I 型误差 R~0"的同样二项尾上界。再用 Lemma 1（第15页）：D(c)=R~0(c)-R0(c)=M[F~0(c)-F~1(c)]，M=(1-m0)/(m0-m1)，且 D 的下确界 >=0 的概率 >= 1-eps1，故污染误差高于真实误差。Algorithm 1（第12页）：取 k^ = min{k : delta_{k,alpha} - D^+(t_(k)) <= delta}，其中 D^+ = max(D^,0)，D^ 用留出的两份污染数据的经验分布估计；Algorithm 1#（第13页）把 m0、m1 换成 m0#、m1#。当无噪声时退化为原算法（Lemma 2，第18页）。
- 保证 / 结论：Theorem 1（第18-19页）：P(R0(phi_k^) > alpha) <= delta + eps1(nb) + eps2(nb) + 2exp(...)+2exp(...)+2exp(...)，即渐近保证，余项随样本量趋于0，且定理里需要 eta>0 补偿项，而实验用 eta=0（第17页）。Lemma 3 与 Corollary 1（第19-20页）：Algorithm 1# 的阶 k# 介于原阶 k 与 k^ 之间，同样的上界成立。作者强调（第6-7页）："to have high probability control on the true type I error, we do need the 'under-estimates' as in Assumption 1"，即用"一致且无偏"的估计量也不行。
- 实验：每次生成 2N 条训练数据，N=200 到 2000，1000 次重复，评估集各20,000。Simulation 1（高斯 LDA）Table 1（第22页）：alpha=delta=0.05, m0=.95, m1=.05 时调整后违反率 .026/.031/.038/.053，原算法 .001/0/0/0；Table 2：N 大时 II 型误差 adjusted 约 .350 对 original .491（同组设置，N=2000）。邮件垃圾数据（4601条，57特征，alpha=delta=0.1，m0=.95，m1=.05）Table 8（第26页）：调整后违反率 .080-.096，原算法 0-.004，II 型误差例如 .205 vs .272（按行读出）。Algorithm 1# Table 9（第27页）：低估噪声 m0#=0.97/m1#=0.03 时违反率 .019-.028；m0#=0.95/m1#=0.05（恰为真值）为 .080-.096；m0#=0.93/m1#=0.07（高估噪声，违反假设）违反率升到 .220-.238，超过 delta=0.1。附录 Table 13（用 Liu-Tao 估计量估 m0、m1）违反率 .430-.957（alpha=delta=0.05 列），Table 14（以真值为中心的无偏估计）约 .19-.21（delta=0.1）。基准方法 backward loss correction、T-revision 违反率 .127-.994、.621-.713（Table 7，第25页）。CIFAR10 vehicles/non-vehicles 在附录 D.2（我只读了设置，结果未读）。
- 局限：作者承认——噪声模型是类条件（与特征无关）；需要专家给出低估值；数据驱动的"低估"估计留待将来（第6节）。我看出来的（我的判断）——定理是渐近的，有限样本违反率在表中接近或略低于 delta，无严格有限样本保证；主要实验是表格/合成数据与 CIFAR10，无工业缺陷检测；和我们的相关性在于"标注错误"，不是"部署数值漂移"。
- 和我们的关系：背景 + 需区别。若缺陷标注有错，原版 NP/LTT 校准在类条件噪声且满足 Assumption 3 时对"真实缺陷"偏保守（II 型误差/误报增加），不会违反保证；若噪声不是类条件、或 m0<=m1，则这一结论不成立。我们若想去噪校正，需要标注团队提供噪声率的保守界。它不涉及量化/部署。
- 可引用的句子：（1）即使忽略标签噪声，原 NP 伞形算法仍能控制 I 型误差，代价是过度保守、功效大幅下降（摘要，第1页）。（2）要保证真实 I 型误差的高概率控制，需要噪声程度的"低估"，无偏估计量不够（第6-7页，Table 14）。
