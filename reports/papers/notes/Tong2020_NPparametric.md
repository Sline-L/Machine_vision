# Tong, Xia, Wang, Feng 2020 NP 分类：参数化阈值与样本量要求
- 完整引用：Xin Tong, Lucy Xia, Jiacheng Wang, Yang Feng. "Neyman-Pearson classification: parametrics and sample size requirement". Journal of Machine Learning Research 21 (2020) 1-44. Submitted 8/18; Revised 12/19; Published 1/20. arXiv:1802.02557v5 [stat.ME], 28 Jan 2020. DOI 原文未见（首页给 http://jmlr.org/papers/v21/18-577.html）。License CC-BY 4.0。
- 来源核实：本地 OA_arXiv/1802.02557.pdf，44页；首页为 JMLR 排版 + arXiv v5 戳，与已知元数据一致。
- 阅读深度：第1-3节（含 3.3 对伞形算法 Proposition 1 的重述、3.4 的 Lemma 2/3 开头）、第5节（自适应划分）、6.3、6.4、第7节（Discussion）读了；第4节 NP oracle 不等式的理论与附录证明未读；6.1、6.2 仿真只看了章节开头与 Table 3 邻近文字。
- 一句话：在 LDA（线性判别分析）高斯模型下给出不需要最小样本量的参数化阈值规则，同时重述并确认了非参数伞形算法的最小样本量 n >= log(delta)/log(1-alpha)，并提出自适应划分类0样本的方法。
- 问题设定：同 Tong 2018：类0为优先保护类，目标 P(R0(phi) > alpha) <= delta0。本文假设 X|Y=0~N(mu0,Sigma)、X|Y=1~N(mu1,Sigma)（共同协方差，第4页）；采样方案为三个相互独立的 i.i.d. 样本 S0、S0'、S1（第5页）。
- 方法：（1）非参数阈值：同伞形算法，C = s_(k)，k=min{k: v(k)<=delta0}（公式11、12，第6页）。（2）参数化阈值：对固定方向 beta，利用高斯性，用 t 分布给 beta'mu0 的单侧上界（Lemma 2，第7-8页），用 Bloemendal et al. 的最小特征值集中不等式给 beta'Sigma beta 的样本上界（Lemma 3，第8-9页，需要 (n-2)^(1/C) < d < n-2 等条件并是渐近的），合成 C^p。（3）自适应划分（第5节）：对划分比例 gamma 在 {0.1,...,0.9} 上做 K 折交叉验证 II 型误差，取最小者。
- 保证 / 结论：Proposition 1（第6页，公式11）：P(R0(phi_k) > alpha) <= sum_{j=k}^{n0'} C(n0',j)(1-alpha)^j alpha^(n0'-j)；"When Ti's are continuous, this bound is tight"；证明靠"permutation 的对称性"。最小样本量（第7页）："there exists a minimum left-out class 0 sample size requirement n0' >= log delta0 / log(1-alpha)"，并说明 "the control on type I error violation rate does not demand any sample size requirements on S0 and S1"（它们只影响 II 型误差）。引言第3页例子：alpha=0.05, delta0=0.05 时要求 59，而 mesothelioma 类共 31 例，不够。参数化规则下 NP-sLDA 满足 NP oracle 不等式（第4节，未读证明）。
- 自适应划分与保证的关系（第5节，第17页）：作者明确写道，若"对每一个数据实现都先做自适应划分再做NP分类"，则"the overall procedure indeed does not lead to a classifier with type I error violation rate controlled under delta0"；只有"对一次实现得到划分比例后，在其余实现中固定该比例"才保持控制。
- 实验：6.4节：neuroblastoma（d=43,827, N=498，176 HR=类0），alpha=delta0=0.1，1000次随机划分（70%训练/30%测试），Fig.6 中四种方法平均 I 型误差均低于 alpha；乳腺癌（d=22,215, N=118，类0=75，类1=43），delta0=0.1，alpha 从 0.05 到 0.15，Table 3（第27页）：alpha=0.05..0.08 时 NP 伞形算法 vio 为 NA（样本量不足），pNP 的违反率为 0.021/0.025/0.029/0.015；alpha=0.09 与 0.10 时 NP 的 vio=0.111，type II=0.448，pNP 的 vio=0.015，type II 分别为 0.536、0.515。计算平台：HP Enterprise XL170r、CPU E5-2650v4、16GB（脚注3，第25页），无 GPU/嵌入式实验。
- 局限：作者承认——非参数规则要求最小类0样本量；参数规则依赖 LDA 高斯假设；QDA、重尾分布留待以后（第7节）。我看出来的（我的判断）——参数化规则的高维 Lemma 3 是渐近结论；Table 3 中伞形算法在 alpha=0.09、0.10 时 vio=0.111 超过 delta0=0.1，正文所读部分未解释（测试集仅约 1/3 的75个类0即约25个，经验违反率噪声大，这是推测）；违反率是经验近似（脚注2，第21页）。
- 和我们的关系：背景 + 需区别。两条可用信息：（1）样本量公式在 JMLR 正式文献中被明确写出（第7页），我们的校准集中"缺陷"零件数需 >= log(delta)/log(1-epsilon)。（2）自适应选择（划分比例、阈值）若用同一校准数据反复选取，则保证失效（第17页），对应我们用校准集挑量化方案或阈值时的数据重用问题。区别：本文参数化规则靠 LDA 高斯假设，对 CNN 打分不适用。
- 可引用的句子：（1）"the control on type I error violation rate does not demand any sample size requirements on S0 and S1"（第7页）。（2）对每个数据实现都自适应划分会破坏 violation rate 控制（第17页）。（3）alpha=delta=0.05 时左出类0样本需 59（第3页）。
