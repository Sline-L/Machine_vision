# Tong, Feng, Li 2018 NP umbrella algorithm 与 NP-ROC（Neyman-Pearson 伞形算法）

- 一句话：给任意"打分型"分类器配一个由左出（left-out）类0样本的顺序统计量决定的阈值，使"类0被判为类1"的总体 I 型误差超过 alpha 的概率不超过 delta；而"经验 I 型误差 <= alpha"这种朴素做法只有约一半概率达标。
- 问题设定：二分类，类0是被优先保护的类（其被误判为类1称 I 型误差，R0）。要求 P(R0(阈值分类器) > alpha) <= delta（delta 称 violation rate 容忍度，默认 alpha=delta=0.05）。输入是 i.i.d. 训练样本；类0样本随机分成两半，一半（与类1）训练打分函数 s，另一半（大小 n）只用来选阈值。假设：训练打分用的数据与左出类0样本独立；类0样本 i.i.d.（作者在 Discussion 里把"各类内样本 i.i.d."列为局限，第11-12页）；Proposition 1 不需要分布假设，但要得到"等号/紧"需要得分连续（第7页）。
- 方法：（1）算 v(k) = sum_{j=k}^{n} C(n,j) (1-alpha)^j alpha^(n-j)，即 Binomial(n, 1-alpha) 取值 >= k 的概率（原文公式1，第7页）；（2）取最小的 k 使 v(k) <= delta（公式2）；（3）左出类0得分排序后取第 k 个顺序统计量 t_(k)，分类器为 I(s(x) > t_(k))（算法1，第6页）；（4）p>1 次随机划分时对 p 个分类器多数投票（算法1第19行）。另提出 NP-ROC band：横轴为 I 型误差上界 alpha，纵轴为 1 - 条件 II 型误差的高概率上下界。
- 保证 / 结论：Proposition 1（第7页）："the probability that the type I error of the classifier exceeds alpha is under a constant that only depends on r and alpha"，即 P(R0(phi_k) > alpha) <= sum_{j=k}^{n} C(n,j)(1-alpha)^j alpha^(n-j) = v(k)；得分连续时等号成立（"this bound is tight"）。证明在补充材料（约第19页），用到"F 连续时 X_(k) < F^{-1}(1-alpha) 当且仅当至少 k 个 X_i 小于它"，并注明证明不需要对 F 的假设（Remark）。最小样本量（第7页与第11页）：要求 v(n)=(1-alpha)^n <= delta，故 n >= log(delta)/log(1-alpha)；Discussion 第11页写成 n_min = ceil[log delta / log(1-alpha)]，指的是"左出的类0样本量"，不是类0总量。p>1 的集成：作者只说"在数值实验中（Simulation S2）"保持了 I 型控制（第7页），Proposition 1 只对 p=1 给出理论保证。
- 实验：Simulation 1（第5-8页，Fig.2）：X|Y=0~N(0,1)，X|Y=1~N(2,1)，n=1000，重复 N=1000 个数据集，alpha=0.05。朴素法（令经验 I 型误差 <= alpha 的最小阈值）"only approximately half of these classifiers have type I errors below alpha"；5折CV法"still only about half"；NP伞形法（alpha=delta=0.05, p=1）这些分类器 I 型误差低于 alpha 的概率至少 1-delta。真实数据1：Early Warning Project，6365 个观测、其中仅 60 个类0，32个特征；真实数据2：neuroblastoma，498个样本（176 HR 为类0、322 非HR），43,827个特征，alpha=delta=0.1，100次随机 3/4:1/4 划分，结果表述为"effectively controls the empirical type I errors under alpha with high probability, by paying the price of having larger empirical type II errors"（第10页；具体 Table S2 数值我未读）。无硬件、无计算量实验。
- 局限：作者承认——需要各类内 i.i.d.（第11-12页）；左出类0样本必须 >= n_min，否则无法达到控制，需放宽 alpha 或 delta；不对 II 型误差给最优性理论（"optimality result cannot be established for the type II error without assumptions"，第5页附近及Discussion）。我看出来的（我的判断）——只对"单个阈值、单个类0误差率"给保证，没有处理两个阈值联合校准或多重检验；保证是对"类0样本"的误差率，不是"零件级（part-level）"误差率，零件级需要自己定义类0单元并保证 i.i.d.；保证是对"整个校准抽样过程"的概率，不是对已固定的单个部署模型的保证；未涉及分布漂移或部署后数值误差。
- 和我们的关系：需区别 + 背景。可直接借用其单阈值、单误差率的"顺序统计量 + 二项尾"规则作为 t1 或 t2 之一的单阈值基线。区别：我们要 (t1,t2) 联合校准、最小化探测器调用率与误报、并检验在 Jetson TensorRT 引擎上是否仍成立；本文不涉及这些。该文是单阈值特例，不能直接声称覆盖我们的联合阈值（我的判断）。
- 可引用的句子：（1）朴素的"令经验 I 型误差 <= alpha"并不能以高概率控制总体 I 型误差，仿真中约一半达标（第5-6页，Simulation 1）。（2）在得分连续时，P(R0 > alpha) 的上界 v(k) 是精确值（第7页，Proposition 1）。（3）高概率控制至少需要左出类0样本数 n >= log(delta)/log(1-alpha)，如 alpha=delta=0.05 时为 59（第11页）。
- 疑点：（A）第11页示例写 "n_min = 45 when alpha = 0.1 and delta = 0.05; n_min = 29 when alpha = 0.05 and delta = 0.1"。按文中公式计算：alpha=0.1, delta=0.05 得 log(0.05)/log(0.9)=28.43，取整 29；alpha=0.05, delta=0.1 得 log(0.1)/log(0.95)=44.89，取整 45。两个示例数值与 alpha、delta 对调了（已看页面图像确认，不是文本提取错误）。引用时应以公式为准：59/29/45 对应 (0.05,0.05)/(0.1,0.05)/(0.05,0.1)。（B）已知发表年/期刊在PDF中原文未见。（C）p>1 集成的保证只有数值证据。（D）Simulation S2、Table S2 未读。
