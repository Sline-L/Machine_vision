All descriptions on the GearPro GitHub (READMEs, docs/, handoff prompts, earlier report drafts) were written by AI so group members could follow along. Treat them as a source of facts to verify against code/records, not as writing to imitate.

**Why:** The user rejected an abstract whose first sentence ("本项目面向齿轮外观质检，研究……的可行性") echoed that generic AI phrasing and did not say what the project actually does.
**How to apply:** For report writing, write fresh plain Chinese. The first sentence of an abstract or introduction must state the problem and what was built (e.g. "针对……问题，本项目……设计并实现了……系统"), then data → method → results → status. Related: [[gearpro-report-decisions]]
