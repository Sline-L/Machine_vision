On 2026-10-09 the user asked for a Jetson-deployment-only literature review and "one-sentence idea + innovation" for the NX paper. Review file (uncommitted, worktree reverent-pascal-e61bd1): `reports/research/GearPro_Jetson部署与加速文献综述.md`.

Directions drafted: A prior-aware conditional cascade (cheap classifier first, 960-input detector only when uncertain, gate threshold under a miss-rate bound); B takt-time-constrained minimum energy per part via power mode/DVFS; C whole-cascade GPU/DLA mapping (weakest novelty); D per-model precision chosen by verdict flips; E dual cameras on one NX.

Closest prior works read in full or part: Raju arXiv:2608.11770 (DLA classifier + GPU detector on Orin NX, no power measured, no contention measured); Hossen arXiv:2608.14727 (Nano fabric cascade: ~91% of the 1.36x speedup was decode overlap, authors estimate a threaded YOLO-only baseline would beat the cascade); Kang arXiv:2606.16106 (Orin deadline-aware DVFS needs EMC state; max clock vs lowest feasible clock gave nearly equal mJ per inference on MobileNetV2).

2026-10-14 advice: user plans to work solo (max one teammate). Recommended A with gate threshold set by distribution-free risk control (answers the 0.3003 criticism), validated on own gear data plus 1–2 public defect datasets and standard YOLO baselines, first target SPL, fallback 中国图象图形学报/物联网学报. Prior art bounding "risk-controlled thresholds": Jazbec arXiv:2405.20915 (early-exit risk control), arXiv:2509.23666, arXiv:2602.03043 — novelty must come from the two-model defect cascade + part-level miss bound + on-device measurement, not risk control itself. B not recommended for solo. 2026-10-14 (later) proposed as the single direction: Neyman–Pearson cascade (cheap classifiers gate, detector only on uncertain parts; two thresholds calibrated jointly by Learn-then-Test so part-level miss rate ≤ ε w.p. 1−δ; minimise detector call rate / false alarms; measured on Orin NX). Extra close prior: Huang/Simeone arXiv:2510.17543 (edge-cloud conformal cascade, CIFAR-100/TeleQnA, no latency measured). Data constraint found: scratch-v5 val has only 43 scratch / 107 normal (1 miss, 9 false alarms at 0.3003) → certified miss bound ~9% at best; need ~150 (ε=2%) to ~300 (ε=1%) defect calibration samples, hence public datasets. 2026-10-15 objective ranking written to `reports/papers/GearPro论文方向说明.md` §3.1: 1) A + H (H = does the miss guarantee survive TensorRT FP16/INT8/DLA deployment; recalibrate on deployed engine; LLM analogue arXiv:2608.01460 shows quantization breaks CP coverage), 2) H alone if cascade saves little compute, 3) I full-chain measurement paper as 物联网学报 fallback. Rejected B, C, E, F (YOLO modules), G (unsupervised AD, too crowded). Data stance (§5.2–5.3): KolektorSDD2 (356 defects, re-split) + Severstal (≈6666 defects, for sample-size curve) as main; DAGM rejected as near-solved; gate ResNet18, expert YOLO11n, gear = existing Scratch V5 as case. Earlier wording: public datasets (KolektorSDD2, DAGM) + public architectures for main results, gear data as case study; publish per-sample score tables; split by part not image. 2026-10-15 lit search (3 agents) → proposed H as main line, A as object; full review + roadmap in `reports/papers/A+H_文献综述与技术路线.md` (uncommitted). Key priors: Tong 2018 Sci Adv NP umbrella (= A with t1 fixed), LTT arXiv:2110.01052, Calibrate-Then-Delegate arXiv:2604.14251 (probe→expert, one threshold, overall error), Zhu arXiv:2608.01460 (LLM quantization breaks CP; recal with 50 labels), Shin arXiv:2609.16085 (Orin INT8 cross-backend agreement 958–965/1000). Recalibration on engine needs no new labels (same calibration images) — novelty is measurement + engine-bound protocol. Stage-0 gate: export Scratch V5 to TRT FP16/INT8, compare per-image scores vs PyTorch. Awaiting user decision on H-as-main. 2026-10-15 decisions from user: H is the main line and the paper should be Jetson-centric, not a pure-software/statistics paper; NX usable now; gear data supplement as much as feasible; public datasets for main experiments; INT8 PTQ first, QAT undecided; measure energy; no git commits for now.
