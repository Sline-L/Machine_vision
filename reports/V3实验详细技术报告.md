## 1 结论与适用范围

V3 完成了无近重复泄漏的数据拆分、三分类缺陷判定、正常样本特征距离异常检测、独立与联合缺陷定位、P2 小目标检测头、CLAHE、灰度表示、难例重采样、验证集阈值搜索和一次锁定测试。训练在 NVIDIA GeForce RTX 4060 Laptop GPU 上运行，总耗时约 3.275 小时。

V3 的最终结构将“图像是否应被剔除”和“缺陷位于哪里”分成两个任务。YOLO26n-cls 负责输出 normal、scratch、missing_tooth 三类分数；两个独立 YOLO26n 定位器分别解释划痕和缺齿位置。验证集选择的剔除阈值为 scratch 0.85、missing_tooth 0.65。任一缺陷分数达到对应阈值时，系统判定该图像应被剔除。

锁定测试结果没有达到预设上线目标。划痕图像级 Recall 为 0.364，缺齿图像级 Recall 为 0.789，正常误剔除率为 0.150；目标分别为不低于 0.90、不低于 0.90 和不高于 0.10。划痕定位器在 IoU 0.50 口径下为 0 TP、6 FP、19 FN。缺齿定位器达到 Precision 0.781、Recall 0.481、mAP50 0.445、mAP50–95 0.219。该版本可以用于研究复盘、人工复核和辅助标注，不具备直接驱动生产剔除的证据。

## 2 实验目标与判定规则

V3 的图像级任务追求高召回。对于 scratch 和 missing_tooth，分别要求 Recall 不低于 0.90；对于 normal，要求被任一缺陷类别误判的比例不高于 0.10。定位任务先要求 Precision 不低于 0.50，再在满足该约束的置信度中最大化 Recall，目标 Recall 不低于 0.70。

候选定位器的验证置信度搜索集合为 0.01、0.03、0.05、0.08、0.10、0.15、0.20、0.25、0.30、0.40 和 0.50。每个类别先筛选 Precision ≥ 0.50 的阈值，再按 Recall 和 mAP50 依次排序。若某候选在所有相关类别上都无法满足 Precision 下限，则候选总分记为 −1。

图像级 gate 的 scratch 与 missing_tooth 阈值分别在 0.05 至 0.95 间以 0.05 为步长穷举。选择优先级为：先满足 normal FPR ≤ 0.10，再最大化两类 Recall 的最小值，然后最大化两类 Recall 之和，最后选择更低的 FPR。

## 3 数据来源与标注定义

V3 从 343 张原始图像读取数据。存在 XML 且 XML 中只包含 scratch 框时，图像类别为 scratch；只包含 missing_tooth 框时，图像类别为 missing_tooth；没有 XML 时，图像类别为 normal。加载程序要求每张缺陷图的 XML 只含一种缺陷类别，并检查框坐标位于图像边界内。

原始类别分布为 normal 132 张、scratch 79 张、missing_tooth 132 张。视角由宽高比自动推断：长短边比不低于 1.8 为 side，不低于 1.25 且低于 1.8 为 oblique，其余为 face。此规则用于分层拆分和分视角评估，不参与训练标签。

| 数据集 | scratch | missing_tooth | normal | 合计 | face | oblique | side |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 56 | 95 | 92 | 243 | 90 | 95 | 58 |
| val | 12 | 18 | 20 | 50 | 22 | 19 | 9 |
| test | 11 | 19 | 20 | 50 | 20 | 18 | 12 |
| 合计 | 79 | 132 | 132 | 343 | 132 | 132 | 79 |

### 3.1 近重复分组与拆分

程序先计算 64 位 dHash。任意两张图 dHash 汉明距离不超过 2 时直接并为同组。对于文件序号相距不超过 3 的样本，如果宽高比相对差不超过 0.15、dHash 距离不超过 8、64×64 灰度归一化向量相关性不低于 0.92，也会合并，但该规则限制合并后的组不超过 12 张。

最终形成 159 个近重复组，最大组包含 41 张图。拆分以组为单位，以 70%/15%/15% 为目标比例，并同时平衡类别和视角。随机种子为 42，候选拆分搜索 150 次。大于 20 张的组不会分配到验证集或测试集，因此最大近重复组保留在训练集。拆分后重新检查跨集合样本，dHash 距离不超过 2 的跨集合对为 0。

### 3.2 难例清单与重采样

难例来源包括 V2 评估中的 FN 与 FP、包含至少 4 个划痕框或极细长划痕框的样本，以及 side 视角的缺齿样本。V2 中每个 FN 计 3 分，每个 FP 计 2 分；复杂划痕计 2 分；侧视缺齿计 1 分。分数最高的 50 张 train/val 图被写入 `review_queue.csv`，锁定测试图不会进入该清单。

独立 scratch 和 missing_tooth 定位数据在 train 集上对 V2 中出现 FN 或 FP 的样本各增加两份副本。原图表示的标准与 P2 实验因此分别得到 263 张 scratch 训练图和 265 张 missing_tooth 训练图。CLAHE 或 gray 实验还为每张训练图增加一份变换图，因此分别得到 506 张和 508 张训练图。val 与 test 始终保留 50 张原始图，没有重采样或表示扩增。

## 4 系统结构与实验流程

V3 的完整流程如下。

1. 读取 343 张图和 XML，验证类别、图像尺寸及框坐标。
2. 按 dHash、相邻序号、宽高比和灰度相关性建立近重复组。
3. 生成 train、val、test 分组清单并执行跨集合泄漏检查。
4. 训练 ResNet18 与 YOLO26n-cls 三分类判定器。
5. 以 ResNet18 倒数第二层特征建立 normal embedding bank，生成异常分数。
6. 训练八个 25 epoch 定位候选，比较 standard、P2、RGB、CLAHE、gray 和联合双类别方案。
7. scratch 与 missing_tooth 分别选择满足 Precision 下限且 Recall 最高的候选，各进行一次 90 epoch 上限的长训。
8. 在 val 上比较五种 gate 融合策略并搜索类别阈值。
9. 锁定模型与阈值后，只对 test 评估一次；同时输出整体与分视角指标。

### 5.2 YOLO26n 分类器完整参数

YOLO26n-cls 从 `yolo26n-cls.pt` 预训练权重开始，输入 320×320，epochs 上限 60，实际运行 27 epochs 后早停。batch=32，patience=15，optimizer=AdamW，lr0=0.0007，lrf=0.01，momentum=0.937，weight_decay=0.0005，warmup_epochs=3.0，warmup_momentum=0.8，warmup_bias_lr=0.1，AMP 开启，RAM cache 开启，workers=4，seed=42，deterministic=false。

增强参数为 degrees=3.0、translate=0.02、scale=0.0、shear=0.0、perspective=0.0、flipud=0.5、fliplr=0.5、hsv_h=0.003、hsv_s=0.10、hsv_v=0.12、bgr=0.0。MixUp、CutMix、copy-paste、random erasing 和 auto augment 均关闭；分类任务不使用检测 Mosaic。验证在 val 集执行，保存 best 与 last 权重并输出训练曲线。

### 5.3 ResNet18 分类器完整参数

ResNet18 使用 ImageNet 默认预训练权重，将最后一层替换为 3 类线性层。输入统一 Resize 到 320×320，并按 ImageNet 均值 `(0.485, 0.456, 0.406)` 和标准差 `(0.229, 0.224, 0.225)` 归一化。

训练增强包括随机水平翻转、随机垂直翻转；以 0.7 概率执行 brightness=0.18、contrast=0.18、saturation=0.08 的 ColorJitter；以 0.15 概率执行 kernel=3、sigma 0.1–1.0 的 GaussianBlur；执行 ±3°、translate 0.02、scale 0.95–1.05、fill=240 的 RandomAffine。验证集只执行 Resize、ToTensor 和 Normalize。

训练 batch=32，workers=4，pin_memory=true，persistent_workers=true。WeightedRandomSampler 按类别频数倒数采样并允许 replacement。损失为带类别权重的 CrossEntropyLoss，类别权重公式为 `训练样本总数 / (3 × 该类样本数)`。优化器为 AdamW，lr=3e−4，weight_decay=5e−4。训练使用 float16 autocast 与 GradScaler。epochs 上限 50，连续 12 个 epoch 未刷新最佳分数时早停。模型选择分数为 `min(scratch Recall, missing_tooth Recall) + 0.2 × normal Recall`。

### 5.4 正常特征异常检测参数

异常检测不单独训练网络。它使用已训练 ResNet18 去掉全连接层后的 512 维特征，进行 L2 归一化。参考库包含 train 集的 92 张 normal 图。查询图与参考库计算余弦相似度，取最相似 5 个正常样本的平均距离 `1 − similarity` 作为原始异常距离。

对参考库内部，每张 normal 图排除自身后取最近 5 个邻居的平均距离。该参考距离的 50% 分位数作为 low，95% 分位数作为 high；查询分数按 `(raw − low)/(high − low)` 线性缩放并截断到 0–1。最终参考库、low 和 high 保存到 `anomaly_reference.pt`。

## 6 每次实验的参数 内容与结果

### 6.1 实验 C1 YOLO26n 三分类判定器

**内容。** 使用完整 train/val 分类目录训练 normal、scratch、missing_tooth 三分类模型，目标是在验证集上产生可供类别阈值搜索的概率。训练参数见 5.2。

**结果。** 实际运行 27 epochs，用时 47.53 秒；训练 loss 从 0.987 降至 0.047 左右，最佳 val top1 accuracy 为 0.760，出现在 epoch 12，top5 始终为 1.000。训练后期 train loss 继续降低，而 val loss 上升到 1.6 左右，显示小数据集上存在明显过拟合。尽管总体准确率有限，该模型在验证阈值搜索中仍优于 ResNet18 和所有融合方案，成为最终 gate。

### 6.2 实验 C2 ResNet18 三分类判定器

**内容。** 使用类别均衡采样与类别加权损失训练 ImageNet 预训练 ResNet18，参数见 5.3。

**结果。** 实际运行 16 epochs并早停。最佳模型出现在 epoch 4：normal Recall 0.350、scratch Recall 0.917、missing_tooth Recall 0.778，选择分数为 0.848。该模型保留为备选判定器，也为异常检测提供特征，但验证 gate 搜索没有选择它作为最终决策来源。

### 6.3 实验 C3 正常特征距离异常检测

**内容。** 使用 ResNet18 特征和 92 张 train normal 图建立正常参考库，按最近 5 邻居距离计算异常分数，参数见 5.4。

**结果。** 异常分数参与 `classifiers_anomaly` 和 `all` 两种融合候选。最终验证搜索仍选择 YOLO 单模型，说明现有异常分数没有在 normal FPR ≤ 0.10 的约束下提高两类缺陷 Recall 的最小值。输出参考文件大小约 190 KB。

### 6.5 实验 D1 p_s_standard_original

**内容与参数。** 单类 scratch；标准 YOLO26n；原始 RGB；25 epochs，patience 10，batch 16，lr0 0.001；train 263 张，其中 72 张含 scratch，共 163 个框。其他参数见 5.1。

**结果。** 实际完成 25 epochs，训练用时 540.40 秒。统一阈值扫描在 conf 0.40 得到 Precision 1.000、Recall 0.059、mAP50 0.055、mAP50–95 0.033。它与 P2 CLAHE 的 Recall 相同，但 Precision 更高，按候选规则成为 scratch 快速阶段胜者。

### 6.6 实验 D2 p_s_p2_original

**内容与参数。** 单类 scratch；YOLO26 P2 小目标结构；原始 RGB；25 epochs 上限，patience 10，batch 8，lr0 0.001；数据量与 D1 相同。

**结果。** 实际运行 20 epochs 后早停，用时 651.26 秒。统一扫描的最优记录出现在 conf 0.01，Precision 0.174、Recall 0.059、mAP50 0.014、mAP50–95 0.006。Precision 未达到 0.50，因此总分为 −1。P2 增加高分辨率检测头后没有提高划痕召回，并显著增加误报。

### 6.7 实验 D3 p_s_p2_clahe

**内容与参数。** 单类 scratch；P2；训练集同时包含原图和 CLAHE 图。CLAHE 在 LAB 空间的 L 通道执行，clipLimit=2.0，tileGridSize=8×8。25 epochs 上限，batch 8，lr0 0.001；train 506 张，其中 128 张含框，共 286 个框。

**结果。** 实际运行 23 epochs，用时 1375.23 秒。conf 0.01 时 Precision 0.810、Recall 0.059、mAP50 0.065、mAP50–95 0.013。该实验满足 Precision 下限，但 Recall 与标准结构基线相同，且计算开销更大，没有进入长训。

### 6.8 实验 D4 p_s_p2_gray

**内容与参数。** 单类 scratch；P2；训练集同时包含原图和灰度表示。灰度表示先转单通道，执行全局直方图均衡，再复制为三通道。其他配置与 D3 相同。

**结果。** 实际运行 20 epochs，用时 1209.23 秒。conf 0.01 时 Recall 提升到 0.118，但 Precision 只有 0.023，mAP50 0.005、mAP50–95 0.001。大量正常纹理和反光被当作划痕，候选不合格。

### 6.9 实验 D5 p_m_standard_original

**内容与参数。** 单类 missing_tooth；标准 YOLO26n；原始 RGB；25 epochs，patience 10，batch 16，lr0 0.001；train 265 张，其中 115 张含缺齿，共 385 个框。

**结果。** 完成 25 epochs，用时 554.62 秒。conf 0.25 时 Precision 0.636、Recall 0.412、mAP50 0.370、mAP50–95 0.154。该结果明显超过两个 P2 缺齿候选，因此进入完整训练。

### 6.10 实验 D6 p_m_p2_original

**内容与参数。** 单类 missing_tooth；P2；原始 RGB；25 epochs，batch 8，lr0 0.001；数据量与 D5 相同。

**结果。** 完成 25 epochs，用时 838.44 秒。conf 0.50 时 Precision 0.500、Recall 0.103、mAP50 0.072、mAP50–95 0.024。虽然刚好满足 Precision 下限，但 Recall 仅为 standard 基线的四分之一左右。

### 6.11 实验 D7 p_m_p2_clahe

**内容与参数。** 单类 missing_tooth；P2；原图加 CLAHE；25 epochs，batch 8，lr0 0.001；train 508 张，其中 210 张含框，共 692 个框。

**结果。** 完成 25 epochs，用时 1532.51 秒。conf 0.20 时 Precision 0.500、Recall 0.221、mAP50 0.188、mAP50–95 0.075。CLAHE 比 P2 原图提高 Recall，但仍显著低于 standard 原图。

### 6.12 实验 D8 p_joint_standard_original

**内容与参数。** 两类联合检测；标准 YOLO26n；原始 RGB；25 epochs，batch 16，lr0 0.001。训练集 243 张，151 张含任一缺陷，共 430 个框；类别编号 scratch=0、missing_tooth=1。

**结果。** 完成 25 epochs，用时 517.64 秒。统一扫描在两类 conf 均为 0.01 时，scratch Precision 0.191、Recall 0.118、mAP50 0.073、mAP50–95 0.026；missing_tooth Precision 0.540、Recall 0.368、mAP50 0.362、mAP50–95 0.162。scratch Precision 未达到 0.50，使联合候选总分为 −1。联合训练没有解决划痕样本不足问题，也略低于独立缺齿标准模型。

## 8 结果解释与误差来源

第一，划痕是 V3 的主要失败点。快速阶段所有方案的 Recall 都不高，P2 与 CLAHE 没有稳定收益，灰度表示只能以大量误报换取少量 Recall。长训把验证 Recall 从 0.059 提高到 0.118，但测试仍为 0。这种模式与“继续增加 epoch 即可解决”不一致，更符合独立样本不足、划痕标注范围不一致以及加工纹和反光与划痕外观重叠的情况。

第二，缺齿比划痕更容易学习。standard/RGB 在快速和长训阶段都优于 P2。测试中 side 缺齿框级 Recall 为 0.722，说明轮廓清晰时局部检测有效；oblique Recall 0.238，说明遮挡、透视与齿顶重叠是主要困难。图像级 gate 对 side 缺齿 Recall 为 1.000，但同时造成严重 normal 误报，因此不能直接用于自动剔除。

第三，P2 并没有在本数据集上形成普遍优势。P2 提高特征图分辨率并显著增加训练时间，但 scratch 与 missing_tooth 的主要对比都低于 standard。小目标结构只有在小目标信号稳定、标注一致且样本足够时才可能带来收益。

第四，增强无法代替独立样本。CLAHE 和 gray 都只基于已有图生成确定性副本；hard-case 重采样也只是重复已有图。它们可以改变优化器看到样本的频率或对比度，却不会增加新的齿轮、照明、表面状态和拍摄条件。

第五，验证集规模较小。val 只有 12 张 scratch、18 张 missing_tooth 和 20 张 normal。一个样本就会让 scratch Recall 改变约 0.083、missing_tooth Recall 改变约 0.056、normal FPR 改变 0.05。阈值搜索结果因此具有较大离散波动，锁定测试下降是可预期风险。

## 9 可复现性与已知限制

V3 的数据清单、分组 ID、类别、视角和 dHash 已写入 `dataset_defects/auto_search_v3/split_manifest.csv` 与 JSON。每个 Ultralytics 训练目录保留 `args.yaml`、`results.csv`、best/last 权重和曲线。最终测试结果保存在 `outputs/defect_search_v3/final_report.json`。

仍有四项限制需要在复现实验时明确。

1. `deterministic=False`，GPU 算子与 DataLoader 时序可能造成小幅结果差异。
2. 归档 YAML 中的绝对路径使用原 Windows 工作区 `F:\Work\VSCode\Projects\DATASET`；迁移后应更新 data 和 project 路径。
3. P2 配置来自当时虚拟环境中的 Ultralytics `yolo26-p2.yaml`。若 Ultralytics 版本变化，结构与默认参数可能变化。
4. 融合候选 G2–G5 的全部阈值扫描中间结果没有持久化，只保存了最终胜者。现有文件足以复核最终选择，但无法逐点重建所有候选的验证曲线。

## 10 最终推理配置

最终 gate 使用 `gate_yolo26n_cls.pt`，输入 320×320。scratch 阈值 0.85，missing_tooth 阈值 0.65，任一分数达到阈值即 reject。ResNet18 与异常参考文件保留在交付目录，但当前 `strategy=yolo`，不会参与最终决策。

scratch 定位器使用 `scratch_localizer.pt`，imgsz=960、confidence=0.40、NMS IoU=0.70。missing_tooth 定位器使用 `missing_tooth_localizer.pt`，imgsz=960、confidence=0.25、NMS IoU=0.70。定位器的框用于解释，不覆盖 gate 的通过或剔除决定。

## 11 后续实验建议

优先复核 `review_queue` 的 50 张难例，统一连续划痕、细长划痕、成片擦伤和独立缺齿齿位的框法。随后采集真正独立的齿轮和拍摄序列，避免从同一视频连续抽帧补充样本。划痕应重点覆盖 face、side、低对比、强反光与加工纹干扰；缺齿应重点覆盖 oblique 视角。

新一轮实验应重新建立 train/val/test 近重复组，并保留当前 V3 test 作为历史冻结集，不再用它选择阈值。对 gate 建议增加独立校准集或交叉验证，报告阈值敏感性和置信区间。对定位器建议先完成标注一致性抽检，再比较分割模型、局部 patch 分类或更高分辨率检测；在数据证据不足前，不应继续堆叠结构复杂度。
