# joint_det_joint_two_class_p2_960

## 方法

- 任务：统一检测 scratch 与 missing_hole 两类。
- 模型：YOLO26n-P2，输入 960，80 epochs。
- 数据和拆分与统一单类检测基线完全一致。
- 主评价仍为图像级是否命中任意缺陷，类别正确性只作辅助诊断。

## 验证结果

Recall `0.6552`、Precision `0.8261`、F1 `0.7308`、FPR `0.1667`、AUROC `0.8348`、AUPRC `0.8474`，TP/FP/TN/FN=`19/4/20/10`。

在相同误报约束下弱于单类检测基线，说明当前数据量不足以同时承担细分类别与高召回判定。
