# joint_cls_efficientnet_b0_512

## 方法

- 任务：`normal/any_defect` 图像二分类。
- 模型：官方预训练 EfficientNet-B0，输入 512。
- 数据与增强：同统一模型固定拆分，类别均衡、非裁剪轻量增强。
- 训练：CUDA、AMP、早停；验证概率做温度校准，温度 `1.125`。

## 验证结果

在 FPR <=20% 的工作点：Recall `0.9434`、Precision `0.9259`、F1 `0.9346`、FPR `0.1667`、AUROC `0.9057`、AUPRC `0.9449`，TP/FP/TN/FN=`50/4/20/3`。

该候选为统一单模型验证集优胜者，固定阈值 `0.6764997973`。
