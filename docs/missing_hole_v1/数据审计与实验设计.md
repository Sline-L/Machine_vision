
# Missing Hole V1 数据审计与实验设计

## 数据结论

源目录仍沿用历史名称 `*_missing_tooth`，本轮语义名称统一为 `missing_hole`。原图和 XML 不修改，派生数据位于 `dataset_defects/missing_hole_v1`。

| 集合 | 图片 | 缺陷图 | 无 missing_hole | 框 | difficult 框 |
|---|---:|---:|---:|---:|---:|
| 训练池 | 496 | 173 | 323 | 614 | 25 |
| 独立测试 | 150 | 44 | 106 | 168 | 6 |

- 训练池固定拆分为 397 train / 99 val，种子为 `20260913`。
- 采用 SHA256、dHash、相邻序号、宽高比和灰度相关性建立了 270 个近重复组。
- 近重复组没有跨越 train/val。
- 训练池与独立 test 之间没有 SHA256 重复或 dHash 距离不超过 2 的近重复。
- 218 个 XML 的图片尺寸、对象类别和边界框范围均通过检查。
- `test_047.xml` 无对象，按“无 missing_hole”处理。

## 标签派生

生成三类、两类和单类三种语义方案，每种方案包含 `include_difficult` 和 `exclude_difficult` 两套训练策略，共六套 YOLO 数据。

`exclude_difficult` 只修改训练数据：删除 difficult 框；若一张训练图只含 difficult 框，则整张图片排除。本次共有 6 张此类训练图。验证集和测试集始终保留完整真值，以保证实验可以公平比较。

无 missing_hole XML 的图片是 missing_hole 专项任务的负样本，其中允许存在 scratch。这些图片不能在“任意缺陷”联合任务中直接视为正常。

## 选择标准

1. 所有模型、TTA、温度校准、融合规则和阈值只使用 val。
2. 主工作点要求正常误报率 FPR 不超过 20%。
3. 在约束内优先最大化图像级 Recall，其次关注最差位置子组、AUPRC 和 NPV。
4. 检测框 IoU 只作定位诊断，不作为生产判定的首要标准。
5. 独立 test 在最终配置锁定后一次性运行。
