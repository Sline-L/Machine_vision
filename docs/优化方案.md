## Step 1: 数据集

### 测两次

投入 CNN 的图片不是原图，图片像素量（比如 640\*640）一般远小于拍摄图片质量
会导致缺陷可能只有几个像素点，那就不可能查得出来

![[Pasted image 20260802084848.png]]

两种可能的解决方法：
1. 可能的优化方案如上图，检测两次
2. 精密设计传送带和摄像头位置，确保齿轮刚好占满整个屏幕

方案2可能涉及到最近对焦距离问题与泛用型问题

### 数据集的选择

一般分：训练集，验证集，测试集

1. 同一个零件、同一批拍摄角度的相似图片不要同时出现在训练集和验证集
2. 测试集不参与修改模型

我感觉比例7:2:1差不多

我们应该要改传送带结构吧，最好是用工业相机拍数据集，上下两个镜头都要拍，齿轮放亚克力板上拍
可以先用现在的结构拍一些，我先训练起来

一些可能的人为数据处理方法：
1. 不能依赖yolo自动的数据增强，可能人家一缩放划痕就小到检测不出来了，且很多自动处理方法不适合我们的微小缺陷
2. 人为可以做这些事情：
    1. 旋转，平移，缩放
    2. 模拟过曝/欠曝
    3. 模拟反光
    4. 噪声
    5. 模糊，模拟没对上焦

正常样本也要做上述处理，且很可能有灰尘/加工痕迹，但不是缺陷，容易误识别

可以提高样本训练分辨率试试，希望电脑吃得消

### 多轮训练

引用 hard case 重采样

训练完后，把错误样本分出来，大部分应该是很难识别的样本

然后在下一次训练时增加上一轮训练时错误样本在其中的占比

### 消融实验

每次只改一个数据策略：  
  
- Baseline  
- Baseline + 光照增强  
- Baseline + ROI裁剪  
- Baseline + hard case重采样  
- Baseline + 高分辨率训练

### Head

经过[[#测两次]]后，手动标注后，看一下微小缺陷的大小
然后代入上述流程图中，算一下到P2,P3时缺陷有多大
**可见测两次的重要性**，如果不测两次，假设原图缺陷大小 3\*3, 那到P2就已经是0.75\*0.75了，所以不可能检测不出来

如果测两次还是不行，只能考虑进一步增大输入图像的分辨率，比如640\*640改成1280\*1280，但会带来计算量的巨量提升，就看jetson能不能吃得消了

#### 忽略 P5

对于缺齿情况，P5大概率是有必要的
但对于划痕情况，极其微小的缺陷在P5早就已经无法检出，若最后运行速度过慢可以考虑：
1. P5向上融合到P3,P4，删去P5检测头
2. 删除Neck自底向上的P5融合分支
3. 直接卷积到P4就停止

### Neck

![[Pasted image 20260802120700.png]]

1. 增加P2融合深度（x2 -> x4）（有效 1 -> 2）
2. 增加P2输出通道数（192 or 256）（实际 48 or 64）

## Step 5: 性能优化

在模型精度已经足够高的情况下，我们开始考虑优化模型在jetson的推理速度

### INT8量化

老生常谈，效果很好且对性能影响还好
当然也可以试试FP16，如果速度够用没必要INT8

### 模型拆分

缺齿和划痕的大小差异很大，在上文 [[#Head]] 中曾提及

如果一个模型无法兼顾这两种大小的缺陷，可以考虑拆分成多个模型

### 几何归一化

很神秘的方法，在检测模型前把齿轮进行各种处理，包括：

- 定位齿轮中心
- 统一齿轮尺寸

以及有可能可以
- 裁剪环形齿区
- 校正旋转角度
- 必要时将圆周区域展开为矩形条带

这样图案更规则，理论上模型能更好学习

### 剪枝

#### 少用非结构化剪枝

虽然变快，但很影响精度

#### 选用结构化剪枝

找一些长期响应弱的通道，剪掉
模块剪枝
