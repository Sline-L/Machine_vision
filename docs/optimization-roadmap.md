# 齿轮检测模型优化路线

本文档记录后续实验方向，不代表当前程序已经实现全部优化。实验应遵循“先建立基线、
每次只改变一个变量、保留独立测试集”的原则。

## 1. 数据集与成像

### 两阶段检测

直接把整张相机图像缩放到 CNN 输入尺寸会让微小划痕只剩几个像素。当前工程采用两阶段
方案：先定位齿轮，再把齿轮 ROI 送入缺陷分类器。另一种方案是精确固定传送带和相机，
让齿轮始终充满画面，但需要同时解决最近对焦距离和设备泛化问题。

### 数据划分

- 建议按约 7:2:1 划分训练集、验证集和测试集。
- 同一零件或同一批连续拍摄的高度相似图片不能跨训练集与验证集。
- 测试集只用于最终评价，不参与阈值选择或模型修改。
- 最终数据应使用上下两个工业相机，在实际亚克力承载结构和照明条件下采集。

### 人工增强与困难样本

微小缺陷不应完全依赖 YOLO 默认增强，因为缩放可能抹除缺陷。训练集与正常样本均应
覆盖旋转、平移、有限缩放、过曝/欠曝、反光、噪声和失焦模糊，同时保留灰尘及正常加工
痕迹等易误报样本。每轮训练后收集误检和漏检样本，并在下一轮提高 hard case 占比。

数据策略消融顺序：

1. Baseline。
2. Baseline + 光照增强。
3. Baseline + ROI 裁剪。
4. Baseline + hard case 重采样。
5. Baseline + 高分辨率训练。

## 2. 训练配置

依次比较输入尺寸、batch、epoch、学习率、优化器、置信度阈值和 NMS IoU 阈值。优化器
至少比较 SGD 与 AdamW；使用相关预训练权重而不是完全从零训练；启用早停并记录过拟合
开始的 epoch。Jetson 推理延迟和显存是输入尺寸与 batch 选择的最终约束。

## 3. 检测结构实验

### P2 与 P5

P2 对微小划痕很重要：缺陷在连续下采样后可能不足一个特征点。优先验证完整 P2 检测头，
再比较减少隐藏通道和轻量卷积分支。P5 对缺齿等较大结构缺陷仍可能有效；只有在精度证明
不受影响且部署速度不足时，才实验移除 P5 检测头或相关融合分支。

### Neck 与注意力

按顺序进行以下消融：增加 P2 融合深度、增加 P2 输出通道、加强 P3，再考虑继续加强
P2。注意力模块成本较高，先在 P4 融合节点测试 C3k2-attn，再测试 P3；每一步都记录
精度、延迟、显存和功耗。

## 4. 其他精度方法

- 几何归一化：定位齿轮中心、统一尺寸、裁剪环形齿区，必要时校正旋转或展开圆周区域。
- 知识蒸馏：训练高精度教师模型和轻量学生模型，部署时仅保留学生模型。
- 模型拆分：当缺齿与划痕无法由同一模型兼顾时，分别训练并组合结果。

## 5. Jetson 部署优化

格式层面的顺序是 `.pt` 基线 → ONNX 数值对照 → 在 NX 本机编译 TensorRT。
细节见 [模型格式](model-formats.md)。不要跳过 `.pt` 基线直接上 INT8。

1. 先在 NX 上用当前 `.pt` 跑通，再用 `trtexec` 区分模型耗时与预处理、Qt、
   内存复制耗时。优先给占时更多的 YOLO 定位模型做 TensorRT。
2. 在精度满足要求后优先测试 FP16，再评估带校准集的 INT8。微小划痕对量化
   更敏感，INT8 必须用独立测试集回归。
3. 减少 CPU/GPU 内存复制，尽量让预处理和模型输入留在 GPU 或 Jetson 硬件缓冲区。
4. 只采用结构化通道或模块剪枝，避免缺少硬件加速收益且容易损伤精度的非结构化剪枝。
5. 只有上述方法仍无法达到吞吐目标时，再考虑定制 CUDA；同时评估可维护性和可迁移性。

所有实验至少记录准确率、召回率、缺陷类别指标、单帧延迟、吞吐、峰值显存和 Jetson
功耗，并保持测试集与硬件环境一致。
